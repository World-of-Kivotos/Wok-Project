## ① 设计原则与用户已拍板前提

### 用户已拍板的前提

1. **硬规则**（用户原话：“这个饭的低品质是什么效果，永久 BUFF 级就是什么效果”）：同一道菜从低品质到闪耀永久，给同一个效果、同一个数值，只有时长不同。所以效果池里**每个效果都能进永久池，永久值 = 限时值**；永久会过强的效果，只能压数值、加冷却、加条件，不能排除出永久池，也不能给永久打折。
2. 一道菜固定一个厨师效果。**菜品星级（★1–★7，按食材获取难度计分）决定数值；品质决定时长**：低 3 分钟 / 中 8 分钟 / 高 15 分钟 / 超凡 30 分钟 / 闪耀 = 单命永久（死亡清空）。
3. 三大类：战斗 / 探索 / 增益（效果不够多样时允许加大类）。**永久槽每类 1 个**，同类再吃闪耀直接覆盖。**盛宴只有第一份算永久**，其余份限时。
4. 与酿酒师等的同属性 buff 可以叠加，不共用上限。插板护甲会把原版护甲值清零，所以不用“+护甲”，改用黄心护盾。生命上限按“% 基础血量”算（基础血 80）。
5. 非厨师做出的是“家常菜”：只有菜原本的效果，没有厨师效果。
6. 旧的厨师饱食类效果（增香 / 增量 / 回味）保留为“吃下当刻”的品质层；翻车负面（低 / 中 / 高品质）保留；FD 的舒适 / 滋养是 FD 核心效果，保持原样，不算厨师效果。
7. 本轮新要求：可以根据菜品原有效果微调；增加永久池；**抗性提升这类不能层数太高**；战斗、探索、增益都要多样化，不够可以多几个种类。

### 设计原则

- **不打折，只限形**：永久值 = 限时值。控制强度靠四种手段：压整条曲线、内置冷却、触发条件（低血 / 脱战 / 只对怪 / 只对某种伤害）、每类只有 1 个永久槽。
- **PvP 安全优先**：会影响枪战的通用属性（生命、黄心、通用减伤、抗击退）压得最低；只对怪、只对特定伤害类型的效果数值放宽；所有机动类只在脱战时生效。
- **抗性严格偏低**：厨师效果一律不发原版“抗性提升”；通用减伤 ≤ 4%；唯一的“抗性 I 级”减伤做成低血短窗口 + 长冷却。
- **按百分比的回复和护盾不随金酒 / 塔罗翻倍**：统一按“厨师基准血 = 基础血 ×（1 + 体魄%），最多 88”计算。
- **多样化**：41 个效果覆盖数值型、条件触发型、开关型、机制型、生产 / 经济型；多样性主要落在 PvE、地形和生产侧，枪战侧保持克制。

### 本版（v3）相对上一版的主要改动

- 补上漏分配的鱿鱼烤串；204 道菜全部分配（战斗 69 / 探索 67 / 增益 68）。
- 改派 9 道：寿司拼盘→渔获、热带寿司拼盘→铁胃、春卷拼盘→凝脂、火辣咖喱→回甘、墨西哥鸡肉卷→膳香、蜜汁火腿→回春、猪肉海带水饺→膳香、披萨→悟性、（新增）鱿鱼烤串→饱餐。
- 数值调整：膳香 ★7 10%→8%；赶路 ★7 10%→8%；铁胃 ★7 100%→80%（取消免疫）；夜照 ★2 加“失明/黑暗 −5%”；弹步“登阶”从 ★5 下移到 ★4；披甲取消“≤12 点”特例（改按基准血自然封顶 7.04 点）。
- 规则调整：镇火不再缩短着火时长；回甘 / 夜照只缩短非玩家来源的负面、两者取较高值；坚守 / 回春在“食物战斗增益冷却”中不触发；披甲获得或刷新时不立即给盾；攀爬 / 踏实 / 驭行 / 游速改为只在脱战；举枪瞄准也算战斗；辣味只对怪物；猎手对精英为 0、驱兽对精英减半；家常抗性统一 ≤ 8 秒。
- 实现方案按代码核对结果重写（第 ⑤ 节）：效果用 MobEffect 承载、客户端同步、进食挂点时序、精进 / 惜物 / 匠心 / 耐饥的正确挂点等。

## ② 各大类效果总表

说明：

- ★1…★7 = 该星级菜给的数值，**低品质到闪耀永久都是这个数值**，品质只决定时长。
- “—” = 该效果在这一档没有数值（坚守、回春 ★3 起才有），也没有 ★1–★2 的菜配它们。
- “可永久”全部为“是”，“永久规则”的共同前提是“永久值 = 限时值，单命永久，死亡清空”，表中只写额外说明。
- “已配菜”列出实际分到的星级（×n = 同星级 n 道）。没有菜的档位只作为上限存在，详见 `dish-effects.md` 的覆盖矩阵。
- 基准血 = 厨师基准血 = 基础血 ×（1 + 体魄%），80 血时就是 80，最多 88。

### 备选：第四大类“生产”（待用户拍板）

**本稿决定不新增大类**，理由：

- 三大类各有 13–14 个效果，玩法互不重复，204 道菜分得很均匀（69 / 67 / 68），不存在“装不下”的问题。
- 新增大类等于多一个永久槽，相当于给每个玩家白送一个常驻效果。
- 增益槽里“职业经验 vs 产出类”的取舍本身就是好的设计。

如果用户希望更多选择感，备选方案如下：

- 新大类名：**生产**，包含丰收、沃土、渔获、矿运、惜物、庖丁、多福（7 个）。
- 剩下的增益：精进、悟性、好彩、匠心、聚宝、佐餐、铁胃（7 个）。两类都偏少，建议把耐饥从探索移到生产，再新增 2 个经验 / 交易向的增益效果。
- 平衡影响：PvP 完全中性（不加任何战斗力）；经济侧多一个永久槽，同一个人可以同时永久挂职业经验和矿运 / 丰收，产出约增加 5–15%，需要观察矿价、麦价，并坚持矿运 ≤ 5%。
- 菜品分配不用改：生产类效果在 `dish-effects.tsv` 里的“类别”列改成“生产”即可。

## ③ 抗性类与全局上限、最坏组合测算

### 叠加与槽位规则

1. **同一个效果 id 不叠加**：永久和限时之间、几份限时之间，都取星级最高的数值，各自计时；高值到期后回落到仍在生效的低值。
2. **每类同时生效的不同效果 ≤ 3 个（永久 ≤ 1 + 限时 ≤ 2）**，吃第 3 个限时会顶掉剩余时间最短的那个；同一 id 的永久和限时只算一个名额。这是下面“4 枪必死”验算的前提，**待用户确认**（第 ⑧ 节第 1 条）；不加的话，战斗类 5 件全堆可以稳定撑到 5 枪以上。
3. 永久槽每类 1 个，同类再吃闪耀直接覆盖；盛宴只有第一份算永久；死亡清空全部厨师效果（永久和限时）；非死亡的实体重建（例如从末地出口回主世界）照搬状态。
4. 厨师效果牛奶清不掉、不死图腾清不掉；限时效果只在玩家在线时倒计时（实现见第 ⑤ 节）。
5. **脱战**统一定义：10 秒内没有受到伤害、没有造成伤害、没有开枪、没有举枪瞄准（TACZ ADS）。只在脱战时生效：赶路、弹步（含登阶）、轻羽的潜行缓降、攀爬、踏实、驭行、潜鳃的游速。披甲只在脱战时补满。
6. **厨师基准血** = MAX_HEALTH 基础值 ×（1 + 体魄%），最多 88。披甲、余韵、膳香、回春、饱餐都按它算，不读当前最大生命，所以不会随金酒 / 塔罗的 +100% 翻倍。
7. **食物战斗增益冷却（60 秒）**：原效果里的力量、抗性提升、伤害吸收共用这个冷却，冷却中吃到的这类原效果直接跳过（菜照吃、饱食照给）。**冷却期间坚守、回春不触发，也不进冷却**。
8. **冷却不可刷新**：坚守、回春、膳香、饱餐、辣味的冷却按“玩家 + 效果 id”记在玩家身上，重新进食、限时被顶替、永久被覆盖都不重置，只有死亡清空。
9. 按已拍板前提，厨师与酿酒师、塔罗的同属性 buff 可以叠加，不共用上限（体魄不进 +100% 上限、披甲与原版伤害吸收叠加）。所有厨师减伤都注册进 PlayerDamageReduction，和伏特加、矿工陷阱、塔罗预知一起连乘，受 85% 全局帽约束。**原版抗性提升不在这个 85% 帽内**（在 LivingHurt 之后由原版结算）；原版同名 MobEffect 按原版规则取较高值，不叠等级。

“抗性类永久更低”的实现方式：不对永久打折，而是靠“每类只有 1 个永久槽”。只靠永久时，战斗槽只能在“稳身 / 坚守短窗口 / 驱兽（只对怪）”等里面选一个，天然低于“永久 + 2 限时”的合计。

### 生命、回复、移动、增益上限

- 生命与回复：体魄 ≤ +10% 基础血（+8 HP）；披甲 ≤ 8% 基准血（≤ 7.04 点），只在脱战补满；余韵 ≤ 1.5% / 10s；膳香 ≤ 8% / 30s（只认正餐）；回春 ≤ 12%、冷却 ≥ 120s；饱餐每次 ≤ 6%、冷却 2s，只对敌对生物。
- 移动：交火中厨师给的移速、跳跃、攀爬、地形抵消、坐骑速度、游速恒为 0。赶路 ≤ 8%；弹步起跳 ≤ +22%（低于跳跃提升 I 的 +23.8%）；步高 +0.5；游速 ≤ 15%；坐骑 ≤ 20%；攀爬 ≤ 50%；地形减速抵消 ≤ 50%（不含蜘蛛网）。
- 增益：职业经验 ≤ 10%（与茅台加算）；原版经验 ≤ 25%；幸运 ≤ +2；铁砧 ≤ 20%；作物额外产出 ≤ 12%；矿物 ≤ 5%；牲畜 ≤ 22%；做菜多出一份 ≤ 12%（只出家常品）；工具耐久 ≤ 22%（不含护甲、插板、枪械、剑）；作物生长 ≤ 20%；拾取范围 ≤ +3 格；酿酒饮品时长 ≤ +20%；食物负面缩短 ≤ 80%。

前提：基础血 80，躯干每发 27，3 发 = 81 刚好致死。会影响枪弹的厨师效果只有体魄（V）、披甲（S）、稳身（T）、坚守（L）、回春（M）；稳膛、凝脂、驱兽、猎手、回甘、辣味、饱餐对枪弹无效，余韵每 10 秒最多回 1.32 HP，膳香需要停下来吃正餐，都不影响结论。

### PvP 验算 B：厨师 + 家常原效果

- **开战前喝苹果酒（伤害吸收 I，4 点）**：进入 60 秒食物战斗增益冷却，坚守、回春不触发。
  - V + S + T + 吸收：(88 + 7.04 + 4) / 0.96 = 103.2 < 108，4 枪必死，余量 4.8。
  - V + S + M + 吸收：回春不触发，88 + 7.04 + 4 = 99.04 < 108，4 枪必死，余量 9.0（审查指出的“回春把第 4 发顶过去”已消除）。
- **家常抗性 I 窗口（甜瓜系，≤ 8 秒）**：窗口内单体魄 ★7 就是 88 / 0.8 = 110 > 108，最多 5 枪；V + S + T 为 123.8，也是 5 枪。这一项按“和酿酒师限时抗性同类的短时爆发”接受：≤ 8 秒、60 秒冷却不能连吃、窗口内坚守 / 回春不触发；酿酒师限时抗性 II 可以持续 300 秒，远强于它。
- **断点说明**：27 伤武器的“3 枪 → 4 枪”断点只有 1 HP 余量，★1 披甲（1.6 点）、★1 体魄（2.4 HP）、★2 稳身（1.5%）就能跨过，★1 和 ★7 在这把枪上的结果相同。星级梯度体现在其它伤害的武器、头部倍率、衰减下的断点，以及与酿酒师 / 塔罗叠加后的边际。是否把 ★1–★2 压到不改变这个断点，列为待拍板（第 ⑧ 节第 10 条）。

### 最坏组合：三个永久槽各取最强 + 满层酿酒师

三个永久槽（按实际有菜的最高档，括号内为上限档）：

- 战斗槽：**体魄 ★7**（+8 HP）。对枪弹有效的只有这一槽。
- 探索槽：**镇火 ★6 35%**（上限 ★7 40%），只对燃烧弹、火焰、岩浆有效；或夜照 ★5（失明 −20%）。对枪弹无效。
- 增益槽：精进 ★6 / 矿运 ★6 / 佐餐等，没有战斗力；佐餐只是让酿酒限时饮品少喝几杯（酿酒饮品没有冷却），不提高等级。

满层酿酒师（不算插板）：金酒 + 塔罗 +100%（160 血）、伏特加 5 层 25%（PlayerDamageReduction）、限时伏特加抗性 II 40%（原版，不在 85% 帽内）、限时金酒伤害吸收 III（12 点）、香槟 5 层每秒回 5% 最大生命。

结论：

- 厨师在满层酿酒师之上的边际最多约 15%；只挂三个永久槽时约 5%。上一版自报的“+17%”没有算酿酒师限时抗性和伤害吸收，基数偏小；改成按基准血计算回复后，厨师的绝对贡献固定在 +8 HP、≤ 7.04 点护盾、≤ 10.56 点急救。
- 已有原版抗性（酿酒、塔罗）时坚守不触发，厨师不会把抗性再往上叠一层。
- 真正的爆炸点在酿酒师香槟：5 层在 168 血时约每秒 8.4 HP；厨师余韵 ★7 折合每秒 0.13 HP，只是它的 1.6%。
- 插板（防弹 45–98%，独立管线）在最外层再乘一次，比例不变。
- 燃烧弹场景：镇火 ★7 的 40% 进 PlayerDamageReduction 连乘，与伏特加合计 1 − 0.75 × 0.6 = 55%，仍在 85% 帽内。

### 不做的效果

枪械伤害、射速、换弹、后坐、散布；插板耐久和供电；对玩家增伤（包括近战）；交火中的任何移动加成；原版抗性提升、完整抗火、海豚的恩惠、潮涌能量、急迫等长时 MobEffect；怪物掉落翻倍（通胀风险）。

## ④ 家常菜原效果微调表

### 规则

1. **判定**：物品上没有品质 NBT 的就是家常菜。家常菜只给“微调后的原效果”，没有厨师效果，不掷品质，不吃增香 / 增量 / 回味，也不出翻车负面。tooltip 标“家常”。
2. **同一张表**：家常和厨师出品共用这张微调表。厨师出品 = 微调后的原效果 + 1 个厨师效果（数值由星级决定，品质只决定时长）。
3. **等级**：所有增益类原效果 amplifier 封顶 I 级（抗性 II→I、急迫 II→I、跳跃 III→I）；负面原效果不受这条限制。
4. **战斗类原效果**：力量 ≤ 15 秒；**抗性提升 ≤ 8 秒**（审查后统一）；伤害吸收 ≤ 30 秒；瞬间治疗改为生命恢复 I 5–8 秒。力量、抗性提升、伤害吸收共用每名玩家 60 秒的“食物战斗增益冷却”，冷却中这类原效果跳过；**冷却中坚守、回春不触发**。
5. **机动 / 功能类原效果**（速度、跳跃、缓降、水下呼吸、海豚的恩惠、抗火、急迫、发光、生命恢复）：等级封顶 I 级，时长保持原值不另削（都比原版药水弱）。
6. **负面原效果**（反胃、失明、中毒、饥饿、腐坏）：家常保持原样，作为这道菜的代价；厨师出品统一把时长减半，自身“发光”直接去掉。这条低品质到闪耀都一样，符合“同菜同效”。
7. FD 的舒适 / 滋养保持原样，不算厨师效果，增香可以延长；西瓜汁、热可可这类特殊物品逻辑保持；原效果与酿酒师 / 塔罗给的同名原版效果按原版规则取较高值，不叠等级。
8. **增香黑名单**：力量、抗性提升、伤害吸收、由瞬间治疗改来的生命恢复、跳跃提升、急迫。速度被增香放大后封顶 60 秒。
9. 表做成数据驱动的 JSON（物品 ID → 效果、等级上限、时长上限、冷却组、是否删除），ChefTooltipHandler 同步改写 tooltip。挂点时序见第 ⑤ 节“进食挂点”。

## ⑤ 实现方式备注

### 公共底座

1. **效果承载（取代“capability 存储”与“复用窗口效果”两种互相矛盾的说法）**：每个效果 id 注册一个 ChefWindowEffect（MobEffect）。
   - amplifier = 星级 − 1（0–6）；限时效果的 duration 由品质决定；永久效果用 `MobEffectInstance.INFINITE_DURATION`。
   - `getCurativeItems()` 返回空列表（牛奶清不掉）；监听 `MobEffectEvent.Remove`，对厨师效果取消移除（挡住不死图腾和第三方清除）。
   - “同 id 取最高、到期回落”直接用原版 `update()` / hiddenEffect，存档、登录、客户端同步和图标不用自己写。
   - `PlayerEvent.Clone(!wasDeath)` 时把效果搬到新实体（用 accessor 读 hiddenEffect）；真正死亡不搬运 = 清空。
   - 永久槽另记 {大类 → 效果 id, 星级}（capability，仿 BrewBuffStore），同类覆盖时只移除旧的 INFINITE 实例；“每类 1 永久 + 2 限时”的计数也在这里做。
2. **按星级取值**：ChefEffectMagnitude / ChefConfig 从按品质的 5 元数组改为按星级的 7 元数组；“物品 ID → 效果 id”配表做成数据驱动 JSON。
3. **客户端同步**：ChefNetwork 加 S2C 包，同步每个厨师效果（id、星级、到期）和 inCombat 标志。跳跃、攀爬、地形减速、挖速、水下挖掘在客户端也要算，两端读同一份状态；能用原版属性的（体魄、赶路、步高、游速、坐骑、幸运）用属性，自动同步。
4. **脱战状态 CombatState**：受伤、造成伤害、TACZ 开火、举枪瞄准时刷新；10 秒后脱战；状态变化时下发客户端。
5. **厨师基准血**：`inst.getBaseValue() ×（1 + 体魄%）`，供所有按百分比的回复和护盾使用。
6. **PlayerDamageReduction 命名源**：chef_steady、chef_last_stand、chef_beast_ward、chef_heat_ward（IS_FIRE）；ChefGreaseReduction 改用 IS_EXPLOSION 标签。
7. **进食挂点时序**：`LivingEntityUseItemEvent.Finish` 在原效果施加之后才触发，而且 1.20.1 的 MobEffectInstance 没有公开的改时长方法。做法：在 `LivingEntityUseItemEvent.Tick` 里 `getDuration()==1` 时给玩家打“正在吃 itemId”标记（Finish、Stop、下一 tick 清除）；在 `MobEffectEvent.Applicable` 里对带标记的效果 DENY，把调整后的实例（等级上限、时长上限或比例缩短、冷却组）排队到 Finish 之后 addEffect（ThreadLocal 防重入），或者加 MobEffectInstance 的 `@Accessor` 直接改 duration。家常改写、铁胃、回甘 / 夜照缩短都走这条路，不在 Finish 里事后 removeEffect（会漏掉 hiddenEffect）。
8. **盛宴与出份**：
   - 建“出份物品 → 源菜 ID”映射（含 apple_pie_slice、cake_slice、delightful:pumpkin_pie_slice、roast_chicken、honey_glazed_ham、shepherds_pie、kelp_roll_slice、chicken_roll_slice 等不在 204 道表里的出份）。
   - 放置盛宴时把源菜 ID 和品质记到方块上（FD 盛宴方块没有方块实体：用 SavedData 按 BlockPos 存，方块移除时清理）；每份取出时写 NBT（源菜 ID、星级、品质、是否第一份），效果按 NBT 查表，不按出份物品 ID 查。
   - 寿司拼盘、热带寿司拼盘、春卷拼盘、盘装大炸饺、饺子拼盘的出份恰好是表内单点菜，必须走 NBT，否则会拿到单点菜的低星效果。
   - `unseasonable.json` 去掉 `#farmersdelight:feasts` 整块排除。
   - 蛋糕是放下后右键方块吃，不走 UseItem.Finish，单独挂 `RightClickBlock`。
9. **品质入口**：204 道菜里只有约 100 道是厨锅做的。建议保留调味台（SeasoningTableBlockEntity.produceSingleDish）作为通用“掌勺”工位，厨锅掌勺作为厨锅菜的快捷入口，两条路共用 ChefQualityResolver（待拍板）。`dish-effects.tsv` 已在 104 道非厨锅菜的备注里标出。

## ⑦ 硬规则逐项检查

对 41 个效果逐个检查“同一道菜低品质到闪耀永久同效果同数值、全部可永久、永久值 = 限时值”：

- 41 个效果全部可进永久池，永久规则一律“永久值 = 限时值”，没有任何“永久打折”或“排除出永久池”。
- 坚守、回春的 ★1–★2 为“—”：这是该效果 ★3 起才有，不是永久打折；没有任何 ★1–★2 的菜配这两个效果（TSV 校验通过）。
- 回甘的“生效时清 N 个”、镇火的“吃下当刻熄火”：各品质都只在吃下当刻发生一次，同菜同值。
- 披甲：限时和永久都是“脱战补满到 X%”，不因品质改变；“获得时不立即给盾”对所有品质一样。
- 铁胃：取消 ★7 免疫后，各品质仍是同一百分比。
- 负面原效果“厨师出品减半”：低品质到闪耀一样。
- 盛宴第二份起按超凡计、死亡后锁定（待拍板）：只改时长，不改效果和数值。
- 翻车负面、增香 / 增量 / 回味：属于“吃下当刻”的品质层，不是厨师效果，不进效果池（是否改成按星级固定倍率见待拍板第 9 条）。
- 文件校验：`dish-effects.tsv` 共 204 行数据（+1 行表头），每行的效果在该星级都有数值，五个品质列是同一效果、同一数值，只差时长。

> **2026-10-10 用户拍板**：第 1 条“每类 1 永久 + 2 限时”**同意**；第 2 条“按厨师等级解锁战斗菜（5 级 / 7 级）”**同意**；第 3 条非厨锅菜 → **新做烹饪台**（先做炸锅，从建模开始；其余台子见 stations 方案）；第 4 条防囤闪耀菜 → **暂缓，以后和腐烂系统一起做**；第 5 条盛宴 / 拼盘第二份起按超凡 30 分钟计 **同意**；第 10 条 ★1 起“3 枪变 4 枪” **接受**。第 6–9、11 条仍按本稿默认。
