# 菜品厨师效果分配（定稿）

> 硬规则（用户原话：“这个饭的低品质是什么效果，永久 BUFF 级就是什么效果”）：同一道菜从低品质到闪耀永久，给的是同一个效果、同一个数值；数值只由菜品星级决定，品质只决定时长——低 3 分 / 中 8 分 / 高 15 分 / 超凡 30 分 / 闪耀 = 单命永久（死亡清空）。

- 覆盖：dish-stars.tsv 全部 204 道菜，每道 1 个厨师效果，未分配 0 道。完整逐道明细（含五个品质列、原效果、备注）见 dish-effects.tsv；效果数值、上限、实现见 effect-pool.md。
- 家常菜（非厨师做的，或没进“掌勺”的出品）只给按微调表处理过的原效果，没有下表的厨师效果。
- 盛宴/拼盘只有第一份算永久；出份物品经 NBT 继承源菜的效果、星级、品质（寿司拼盘、热带寿司拼盘、春卷拼盘、盘装大炸饺、饺子拼盘的出份按源菜查表，不按出份物品自身的配表）。

### 覆盖空洞

- 战斗 没有 ★5 以上菜的效果（5 个）：稳身(最高★4)、余韵(最高★4)、凝脂(最高★4)、驱兽(最高★4)、饱餐(最高★4)。这些效果想挂永久，最高只能拿到括号里的星级。
- 探索 没有 ★5 以上菜的效果（5 个）：弹步(最高★4)、潜踪(最高★4)、攀爬(最高★3)、踏实(最高★4)、驭行(最高★4)。这些效果想挂永久，最高只能拿到括号里的星级。
- 增益 没有 ★5 以上菜的效果（5 个）：匠心(最高★4)、丰收(最高★4)、惜物(最高★4)、聚宝(最高★4)、佐餐(最高★4)。这些效果想挂永久，最高只能拿到括号里的星级。
- ★7 只有 2 道菜（烈焰奶酪火锅=体魄、巴克拉瓦=巧手），其余 39 个效果的 ★7 数值目前没有菜能做到，只作为上限写在效果池里；★6 有 11 道。
- 这是结构性的：★5 以上只有 28 道菜，覆盖不了 41 个效果。分配时优先让通用、主力的永久候选（体魄、披甲、坚守、回春、膳香、回甘、猎手、精进、悟性、渔获、矿运、铁胃、镇火、耐饥、察敌、巧手）拿到 ★5 以上。
