# 手枪枪匠组件说明

## 五件套的设计原因

手枪不沿用步枪的六类组件集合。手枪结构更紧凑，基础组件应围绕实际影响射击体验的五个部位组织：枪管、握把、套筒、扳机和击锤。这样可以避免为手枪虚构导气、护木、枪托或枪机组件，同时保留足够清晰的装配选择和品质成长空间。

手枪平台键为 `gunsmith.platform.pistol`，显示为“手枪”或 `Pistol`。手枪部件使用平台索引 2，组件顺序保持全局约定：`CORE0`、`BARREL1`、`BOLT2`、`HANDGUARD3`、`GRIP4`、`STOCK5`、`SLIDE6`、`TRIGGER7`、`HAMMER8`。因此手枪当前使用 BARREL、GRIP、SLIDE、TRIGGER、HAMMER 五类组件。

## 首张验证图纸

M1911 是手枪组件系统的首张验证图纸。它使用 TaCZ 已有的 `tacz.gun.m1911.name` 名称，不在本模组重复创建枪械名称翻译。验证重点包括：五部件是否能被图纸正确要求、机械冲压机是否能产出对应品质、枪械组装台是否能按平台和部件类型完成装配，以及成枪是否保留 TaCZ 的原始射击行为。

## 五部件属性映射

| 部件 | 作用 |
| --- | --- |
| 枪管（BARREL） | 影响爆头倍率 |
| 套筒（SLIDE） | 影响后坐力控制 |
| 握把（GRIP） | 影响操控与开镜稳定 |
| 扳机（TRIGGER） | 影响散射控制 |
| 击锤（HAMMER） | 影响最终伤害倍率 |

射程沿用 TaCZ 原枪数据，不由手枪五件套额外改写。枪管、握把复用现有部件名称和作用文本；套筒、扳机、击锤分别使用新的部件键和对应作用文本。

## 品质与图标

每个部件有五档品质：普通、改良、军规、精密、传奇，对应 `common`、`improved`、`milspec`、`precision`、`legendary`。手枪模型 CMD 按部件分段：BARREL 为 211-215，GRIP 为 241-245，SLIDE 为 261-265，TRIGGER 为 271-275，HAMMER 为 281-285；每段内按上述品质顺序排列。

叶子模型统一使用 `minecraft:item/generated`，`layer0` 指向同名的 `miningdim:item/gunsmith_part_pistol_{part}_{quality}` 纹理。图标应保持低分辨率、透明背景和清晰的原部件轮廓；品质差异使用统一的色阶或轮廓规则表达，不应改变部件的基本形状、比例或辨识度。

## 机械冲压机兼容

手枪五件套沿用现有机械冲压机的部件和品质输出流程。资源命名、平台索引、部件索引和 CMD 必须保持一致，冲压机产出的物品应能直接被枪械组装台识别。新增手枪组件只需要补齐对应语言键、叶子模型和主模型 override；不要通过额外的散落资源目录绕过现有枪匠部件流程。

## 后续手枪图纸规则

未来新增手枪图纸时，应继续复用这五类基础组件，并保留 TaCZ 原枪的射击模式。若某种手枪存在特殊结构，必须在图纸数据中显式定义 `requiredParts`，明确列出实际需要的组件；禁止把全部 enum 值自动当作默认组件集合。图纸数量提示使用动态参数：`%1$s` 为平台，`%2$s` 为所需数量。
