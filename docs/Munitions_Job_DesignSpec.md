# 军火商 职业设计规格（Munitions Job）

> 状态标记：DECIDED = 已拍板；PENDING = 待定。
> 平台：Forge 1.20.1 / Forge 47.x / Java 17。modid：`miningdim`。
> 前置真源：[JobFramework_Shared_Foundation_DesignSpec.md](JobFramework_Shared_Foundation_DesignSpec.md)（统一进度/升级/经济/menu 地基）、[服务器经济系统设计文档.md](服务器经济系统设计文档.md)（货币/弹药 sink/物价）、[ChampionStarAffix_System_DesignSpec.md](ChampionStarAffix_System_DesignSpec.md)（高阶弹供给给精英战）。
> 深度依赖：TACZ（`MCModderAnchor/TACZ`，弹药 = 单 `tacz:ammo` 物品 + `AmmoId` NBT，公共 `AmmoItemBuilder` 构造，无需 mixin）。
> 设计哲学：FF14 生产职——半被动产线、靠走量与供应链赚钱，战斗仅少量加成。

---

## 一、概述与定位（DECIDED）

服务器枪械/弹药**只能买不能自合成**（默认 TACZ 配方禁用）。军火商是**唯一能造弹药**的职业:挂机式制造台被动产弹,卖给战斗玩家与精英战团队。它是经济供应链的关键中游——**矿工产铜 → 军火商搓弹 → 战斗玩家/精英战买弹**。

职业等级 1-10,半被动(制造台自动产弹,腾出时间干别的)。满级净收益 ~17.5 万 CP/日,略高于普通全职业玩家。

---

## 二、核心循环（DECIDED）

1. **收料**:向散户收购火药(P2P,市场定价)+ 向矿工买铜(P2P)。
2. **塞料进制造台**:选口径,塞铜+火药。
3. **被动产弹**:制造台随时间自动消耗料、产弹,存进缓冲区;缓冲满则停产(逼回收),等级越高缓冲越大。
4. **收弹 + 卖弹**:取走存弹,以商店价 75% 卖给战斗玩家(让利抢市场)。
5. **升级**:产弹给经验(谁产谁得),解锁更多制造台 + 更高口径 + L6 发射药提炼(利润质变)。

## 三、弹药制造技术接入（DECIDED）

- TACZ 弹药 = 单一 `tacz:ammo` 物品,口径存 `AmmoId` NBT。**用公共 API `AmmoItemBuilder.create().setId(口径).setCount(N).build()` 直接产出合法弹药 ItemStack**,无需 mixin、无需 TACZ 配方系统。
- 服务器禁用 TACZ 默认 `gun_smith_table_crafting` 弹药/枪械配方(维持买断),军火商的**军火台**是唯一搓弹入口。
- **GUI 复用 TACZ 制枪台贴图**(我方 Screen 引用 `tacz:textures/...`,不拷贝其 PNG → 不触再分发协议;TACZ 客户端硬依赖,资源恒在)。世界方块走自建 block+BE。世界模型已改为自研 GeckoLib 骨骼模型(六档各一套 geo + 512x512 调色板图集,由 `tools/generate_munitions_bench_geckolib_assets.py` 确定性生成),不再借 TACZ 纹理;GUI 仍引用 TACZ 贴图。

### 3A. 枪械配件冲压补充（WIP）

- 命名口径与显示规则见 [枪匠组件命名计划](Gunsmith_Component_Naming_Plan.md)；属性平衡、射速禁区与后续稀有组件规则见 [枪匠组件平衡与后续扩展路线](Gunsmith_Component_Balance_Roadmap.md)。
- **机械冲压机**用于制造枪械配件，不与弹药制造台混在同一产线。
- 机械冲压机先选择枪械平台，再选择部件；不同平台的部件不能混用。
- 当前平台先列 AR、AK；机枪平台的组件规格见[机枪平台组件规格](Gunsmith_Machine_Gun_Components.md)。制作 AR 与 AK 均使用六类组件：基础导气、基础枪管、基础枪机、基础护木、基础握把、基础枪托。特殊枪机仍占用现有 BOLT 槽，不增加第七个 AR 装配槽；机枪平台基础脚架沿用统一组件规则。本文档不据此声明已有机枪图纸或成品枪。
- 弹匣/供弹具暂不进入冲压配件体系；握把与枪托拆成两个独立部件。
- 配件分五档品质：普通、改良、军规、精密、传奇。
- 配件显示名采用“平台 + 基础组件类型 + 品质”格式，例如：`AR基础导气 传奇`、`AK基础枪管 军规`。
- 品质主要通过**配件图标描边颜色**表达，不改变零件本体颜色：普通=白、改良=绿、军规=蓝、精密=紫、传奇=红。
- 组件型号另有制式级、改装级、特种级、尖端级、原型级五档稀有度，并在鼠标悬停 tooltip 中以独立横向名牌显示；稀有度由 `variant` 派生，不覆盖普通、改良、军规、精密、传奇五档品质。具有明确制造来源的特殊组件在名牌右侧显示势力/集团 LOGO，物品图标不叠加稀有度方框或名牌。所有列出具体组件型号的枪匠设计文档、组件规格、平衡表和实现清单都必须逐项记录组件型号稀有度；未声明稀有度的拟议组件不得进入 DECIDED 或实现阶段。详细规则与当前映射见[枪匠组件命名计划](Gunsmith_Component_Naming_Plan.md)第 3.4、3.5 节。
- 品质同时决定配件浮动系数区间，冲压完成时随机 roll 后写入零件 NBT：普通 0.96-1.04、改良 1.05-1.12、军规 1.13-1.22、精密 1.23-1.35、传奇 1.36-1.50。
- 枪械“总体属性系数”取当前图纸全部必需组件品质系数的算术平均值，不以最高品质组件替代整枪品质；六槽枪使用五件最高普通（1.04）和一件最高传奇（1.50）时，总体系数仍仅为 `(5×1.04+1.50)/6≈1.117`。
- 基础组件不得修改射速。任何射速变化只能由后续额外的稀有组件类型提供，并必须绑定明确的负面属性或使用限制。
- 后续可以设计极致强化单项属性的稀有组件，但必须同时降低射速、增加后坐力或承担其他实际生效的代价。讨论中使用的基础伤害 `+30%`、特殊导气伤害 `+60%` 等内容均为说明性示例，不代表属性上限、组件类型或惩罚数值已经定案。
- 试作验证：`M4装配模板` 消耗 AR 六件套并生成 TACZ 默认枪包 `tacz:m4a1`；零件品质与浮动系数写入枪械 NBT，并通过 TACZ 属性缓存事件影响枪机伤害、枪管爆头倍率、导气射程、枪托后坐力、护木散布、握把开镜/瞄准散布以及特殊枪机规则。
- 机枪平台的基础组件仍不改变射速；当前不虚构机枪图纸。后续绑定实际 TaCZ 枪械时，必须保留源枪原有的完整、有序射击模式。

## 四、双推进剂 + 提炼模型（DECIDED）

两种推进剂都能造弹,火药产得少、发射药产得多:

- **火药(gunpowder)**:散户刷/卖,市场定价。低级军火商直接用火药造弹(低产)。供应受散户产能封顶。
- **发射药**:**高级军火商(L6+)用 火药 + 铜 提炼而成**(中间品),提炼后造弹**翻倍**。这是利润质变线。

配方(以步枪弹 762x39 为基准,铜:火药成本 ≈ 45:55):

| 阶段 | 配方(矿料 → 弹) | 产出 | 解锁 |
|---|---|---|---|
| 直造(L1-5) | 7 铜 + 16 火药 → **40 发** | 半产 | L1 |
| 提炼(L6+) | 7 铜 + 16 火药 → 提炼成发射药 → **70 发** | 翻倍 | L6 |

- **工费**:每发额外扣 **1.5 CP 信用点(销毁=弹药 sink)**,L6 提炼与直造都收。
- 高阶弹(狙/反器材/爆炸/特种)按其 TACZ 材料比例缩产(单发料重,出弹数按比例减少)。

## 五、被动生产模型（DECIDED）

类农夫的"塞料→定时产→回收"模型:

- **军火台**(自建方块 + BlockEntity):料槽(铜/火药/发射药)+ 进度 + 输出缓冲区。
- **缓冲满则停产**:逼玩家回收;**等级越高缓冲越大**(收得越省心)。缓冲即天然的离线产量上限。
- **离线追算**:制造台记上次结算时间戳,玩家回来/区块加载时按流逝时间一次性补产,填到缓冲上限即停(无需额外计时器)。
- **总产能 = 制造台数 × 每台速率**,两者随等级涨。
- **性能**:用时间戳追算,只在打开/区块加载时计算,不每 tick 遍历每台。

## 七、升级线（DECIDED）

- 等级 1-10,并入 JobFramework 统一 `EnumMap<JobId,JobProgress>`,复用共享 61,900 XP 曲线 + 每日有效经验软上限衰减。
- **经验来源**:产弹结算(谁产谁得,按产出弹量给经验,封顶随每日软上限);严禁靠"买台子/塞料不产"刷经验。
- 升级解锁:制造台数(1→6)、每台速率、可造口径(手枪→特种弹)、**L6 发射药提炼**(利润质变)。

## 八、散户火药市场（DECIDED）

- 散户(刷怪/苦力怕农场)产火药 → **卖给军火商(收购)**,给非军火商玩家一条收入路径。
- 火药**市场定价**(散户供需浮动,起始 ~15 CP):军火商扩产会抢火药、抬高市场价 → **利润自动压缩(自限)**,无需人工调。
- 军火商优先收便宜散户火药,不够的量用提炼补;铜从矿工买(P2P 溢价,见经济文档量化锚)。

---

## 九、经济耦合与定位（DECIDED）

- **售价 = 商店价 75%**(让利 25% 抢市场);商店是价格天花板,军火商不能宰客。
- **sink**:工费(1.5/发,销毁)是弹药链唯一信用点 sink(火药/铜为 P2P);满级 ~3.6 万 CP/日工费销毁。商店成品弹仍是备用 sink。
- **与商店分工**:商店卖常规弹兜底大头供给,军火商靠便宜 + 高阶弹独占切市场。
- **接精英怪体系**:打 8★+ 世界 BOSS(重型护甲)必须大狙/反器材,其弹药军火商独占 → 把军火商焊进战斗生态。
- **满级净收益 ~17.5 万/日**(略高于普通玩家 + 半被动),靠走量与供应链,非暴利。

## 十、架构与实现（DECIDED）

1. **军火台**:自建 block + BlockEntity(料槽/进度/缓冲输出);GUI 走 JobFramework 公共 menu 脚手架 + 引用 TACZ 制枪台 GUI 贴图;世界模型为自研 GeckoLib 骨骼模型, 经 `MunitionsBenchRenderer`(GeoBlockRenderer)渲染。占地为**水平两格**: 主格在玩家点击的那一格, 副格恒在 `facing.getClockWise()` 一侧, 机身高 25.5/16 格。老存档里 PR 之前放置的台子带 `layout=legacy_depth`, 保持"副格在身后"的旧占位与旧静态模型不变, 只有新放置的台子走 `layout=wide`。
2. **产弹**:`onServerUpdate`/时间戳追算消耗料 → `AmmoItemBuilder.create().setId(口径).setCount(N).build()` 入缓冲;缓冲满停产。
3. **提炼(L6+)**:火药+铜 → 发射药(中间物品);发射药 → 弹(高产)。
4. **工费**:产弹时扣信用点(经 `IEconomyService`/`AbuseGuard` 事务,销毁)。
5. **台数上限**:按职业等级校验,超额不让放置/不运行。
6. **进度**:并入统一 EnumMap;产弹经验谁产谁得 + 每日软上限。
7. 全链路 TDD:产能=台数×速率、缓冲满停产、离线追算填到缓冲上限、工费销毁入账、台数上限校验。
8. **枪械耐久**:仅作用于 WOK 枪匠装配成品，在 `MiningDimGunsmith` 内保存独立耐久 NBT，不占用原版 Damage，不修改 TaCZ/枪包 JSON。初始耐久和每次维修永久损失按 AR、AK、霰弹枪、栓动步枪、精准射手、冲锋枪、手枪等平台分开配置；当前霰弹枪、栓动步枪、精准射手的默认初始耐久分别为 600、800、1000。组件可追加上限倍率修正：圣三一精密刻度枪管使 AR 最大耐久额外降低 30%。每次成功发射扣 1；霰弹枪一次扣扳机只扣 1，连发/三连发按实际发射子弹逐发扣除。归零时保留枪械但禁止开火。
9. **枪械维修**:枪械装配台兼作维修入口——图纸槽改放损耗枪后界面切到维修模式，只开放该平台的关键循环件槽位。维修受一道等级门与一条替换件校验约束，并付出三重代价（工费、替换件、永久最大耐久下降），全部数值落在 `miningdim-munitions.toml`：
   - **等级门** `[gunsmith] repairUnlockLevel`（默认 4）：维修是「替别人修枪」的低阶服务，比装配 `assemblyUnlockLevel`（默认 5）早一级开放；没有这道门，1 级号就能开免费修枪铺，把装配侧的等级门与工费一并架空。
   - **工费 sink** `[gunsmith] repairWorkFeeCredits`（默认 1500 CP，销毁）：与装配工费（默认 5000）独立结算，先扣费再消耗零件。它必须明显低于「弃枪重造」的总价（装配 5000 + 该平台整套组件的冲压工费），否则玩家宁可弃枪重造，耐久体系失去意义；设 0 等于关掉维修 sink。
   - **替换件**：消耗一件同平台关键循环件——AR / AK / 精准射手 / 机枪 / 霰弹枪取枪机，手枪取套筒，无托式步枪 / 冲锋枪取机匣，栓动式步枪取撞针。
   - **永久最大耐久下降**：按 `[gunDurability] <平台>RepairLoss` 扣掉原始上限的固定比例（AK、栓动式步枪、霰弹枪 0.08；AR、手枪、无托式步枪 0.10；精准射手、机枪、冲锋枪 0.12），向上取整且至少 1 点；最大耐久降到 `minimumRemainingRatio`（默认 0.30，即原始上限的 30%）即报废，不得再维修。
   - **替换件同型号且不降级校验**：替换件的组件型号（`variant`）必须与枪上该槽实际装着的组件一致，品质档不低于原件。维修只重写耐久子标签，不重算 Parts/Stats；若放行降级件，最便宜的普通基础件就能给传奇或势力组件枪无限续命，稀缺组件的成本退化成一次性投入。槽位谓词只在放入那一刻生效，换枪后残留在槽里的旧件仍会走到结算，故服务端开工前必须再判一次。
   - 成功后当前耐久回满到**新的**最大耐久。损耗不足（新上限仍不高于当前耐久）时拒绝维修，免得白吃一次永久损失。维修为确定性结算，不设随机失败或直接销毁枪械；装配台在开工前给出维修预览（当前/最大耐久、已维修次数、维修后的新上限、本次永久损失，以及可维修/耐久已满/损耗不足/已报废四种状态）。
