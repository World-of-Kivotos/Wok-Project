## 一、概述与定位（DECIDED）

精英怪分 1-10 星。星级越高，基础数值（血/伤/护甲）膨胀、词条数量与品质上限提升。为防"高星=单纯数值爆炸"，引入**多轴点数预算**：每个词条与基础膨胀都从对应轴的点池扣点，总量受星级封顶——一只怪可以有多种词条但整体战力被钉死在该星级的预算内。

定位三档：

- 1-5★：单人/小队遭遇。
- 6-7★：团队 BOSS（2-4 人）。
- 8-10★：世界 BOSS（约 10 人），需自定义血池 + 分阶段。

本系统是在 Champions Unofficial 开放接口上加的"点数分配器 + 自定义词条 + 安全守卫"层，不 fork 其底层数学。词条由四类组成：生存 / 战斗 / 机动 / 技能（见第七章）。

## 三、红线（DECIDED；含 [红队] 新增/收口条款）

任何词条、任何组合、任何星级都不得越线。红队对抗校验证实：单源封顶不足以防"各自合规、组合越线"的复合退化，故以下多为**聚合级**条款。

1. **净减伤全局硬封顶 ≤75%**（[红队] 收口；2026-07-07 用户定向 49%→75%，前提 = 复合装甲改同源适应给玩家真反制手段）。所有减伤源不得各自独立后相乘穿透。在单一受击拦截点求剩余系数连乘 `keep = ∏(1 - rᵢ)`，统一 `keep = max(keep, 1 - 0.75)`。参与项：`bullet_resistance`、复合装甲当前同源适应层折率、偏斜护盾（按期望值 = 闪避率折算）、刚毅护盾（折算）、缩小化体型（按 ≈ 缩减 ×0.5 折算为有效减伤）。绝无 100% 免伤/全程闪避/等效无敌（keep 恒 ≥0.25，枪械 attrition 永远有效）。
2. **反伤红线**（[红队] 加累计与多源封顶）。反伤一律按"攻击者最大血量的 %"计。`per-attacker` 滚动秒窗：所有反伤源（反击单元 + 反震 + …）累加后统一 `≤30% attacker maxHP/s`（非各源独立）；**单次反击窗口累计 ≤40% attacker maxHP**；必须高亮 + 警告。绝不按"收到伤害的 %"反弹。
3. **不秒杀（按星级预期装备标定）**（[红队] 收口；本版按"高星挑战者装备更好"放宽）。判定基准不是裸 80 血，而是**该星级预期装备水平的玩家**——伤害以 %maxHP 名义值下发、经玩家护甲减免后生效，故精装玩家天然吃得更少。满血玩家不可被一次、一套连段、或任意瞬时（≤0.5s 内）多来源叠加从满血删除；**大额 AOE/核弹命中后给被击玩家 2s 伤害免疫缓冲**（其他来源衰减至 0，DoT 按时间走），由它（而非压低数值）防多来源叠杀。
   - **普通单击（不可躲）按星级抬升**：1-5★ ≤40% / 6-7★ ≤50% / 8-10★ ≤60% maxHP。
   - **带预兆可躲的伤害技能（蓄力/核弹）大胆放宽**：高星高品质可达 60-85% maxHP，因其可躲 + 精装护甲减免；但任何**单次名义值 ≤90% maxHP**（裸血玩家也不被一击从满血删），叠杀由 2s 缓冲挡。
   - 连段（利刃华尔兹）总伤 ≤60% maxHP。
   - **例外**：穿甲等无视护甲的真实伤害不在放宽之列，保守封顶（"精装更安全"的逻辑对真伤不成立）。
4. **持续伤害聚合封顶**（[红队] 新增）。同一玩家身上所有 DoT（燃烧 + 寒霜冻伤 + 强酸 + 穿甲若按 dot 结算）**每秒合计硬封顶 ≤15% maxHP/s**，多 DoT 共存按贡献比例衰减入上限。DoT 刷新受内 CD（≥1s/源）约束，禁止逐跳无限维持满层。
5. **不永控**（[红队] 抬到每玩家聚合维度）。减速总量硬封顶 ≤50%（绝不定身）。同一玩家身上来自**所有来源**的失明/击飞/位移进入统一递减与全局自由窗口：任意 7s 滚动窗内受控总时长 ≤50%，且必须存在连续 ≥2s 完全自由窗（可瞄准/开火/移动）。超出部分作废不入队。
6. **环境致死安全守卫 KnockbackSafetyGuard**（[红队] 新增子条款 5a）。任何各自合规的位移/击退/击飞/换位组合，不得通过环境叠加（推入岩浆/虚空/致死高度）对满血玩家形成确定性删除。详见第九章实现。
7. **不破坏枪械损耗**。不禁用玩家开火/换弹（可加散布）。后坐力是客户端的，服务端不改。
8. **召唤三重封顶**。见第七章"支援"。

## 四、双层平衡模型（DECIDED）

- **星级**决定四个池的总点数预算（生存/战斗/机动/技能）。
- **品质**（普通/中级/高级/超凡/闪耀）同时决定词条强度与点数成本，高品质更强更贵。
- **点数花法**：先买词条（成本 = 基础成本 × 品质系数），**剩余点数换算成基础膨胀**（生存剩→血/减伤，战斗剩→伤害，机动剩→移速，技能池仅供技能不转膨胀）。堆强词条的怪基础属性低（花架子），裸属性怪是肉弹——这就是"词条 + 膨胀 = 星级点数"。

品质成本系数：普通 ×1.0 / 中级 ×1.6 / 高级 ×2.5 / 超凡 ×4.0 / 闪耀 ×6.5
品质随星解锁：1-2★ 普通 / 3-4★ ≤中级 / 5-6★ ≤高级 / 7-8★ ≤超凡 / 9-10★ ≤闪耀
（[红队] 机制层已能挡住"越档取值"；文档中各词条 5 档数值按品质标注，实际可取档由星级钳制。）

## 六、有效血量推演与血池架构（DECIDED）

### 6.1 有效血量

`有效HP = P_dps(45) × TTK × 有效人数`。1-5★ 单人基准；6-7★ 团队；8-10★ 世界 BOSS（约 10 人、有效组队 DPS ≈ 10×45×0.6 ≈ 270/s）：

- 8★ ≈ 270 × 100s = 27,000
- 9★ ≈ 270 × 165s = 45,000
- 10★ ≈ 270 × 270s（4.5min）= 73,000（巨大化闪耀 +180% 后可达 ≈204,000）

"基础有效HP"为生存点几乎全投血量的情形；投了减伤词条则裸血更低、有效血量持平。剩余生存点 → 血量/减伤的换算系数随星级非线性（config 暴露）。

**换算曲线已定（DECIDED 2026-07-07 用户拍板，批2 落地 `ChampionHpConversion`）**：`hpFraction = 0.35 + 0.65 × (剩余生存点/生存池预算)^1.5`，`effectiveHp = 星表基础血 × hpFraction × 体型乘数（巨大化 1+X / 缩小化 1-X）`。FLOOR=0.35 保底防"点全花光=纸怪"（词条效果多为条件触发，全额定价过罚）；GAMMA=1.5 让重仓生存词条比线性多扣血。花费超预算（命令调试）剩余钳 0 = 保底血量，不抛。常量暂硬编码，config 暴露仍属第十三章 PENDING。**体型词条（SIZE 族：巨大化/缩小化）点数豁免换血惩罚**（红队复审修正）：其血量效果已由体型乘数完整表达，再按点扣基础血是双重计价——否则 3★ 巨大化换算后 326/288 血 < 裸怪 360，"+血量词条"净减血且品质越高越亏（语义倒挂）；豁免后巨大化恒为名义 +X%（本节 "10★ 巨大化闪耀 ≈204,400" 的算术即按满额基数，得以保持），缩小化恰为名义 -X%。体型词条点数仍占 PointBudget 预算（挤压其它词条槽位）。效果标定：7★ 复合+超高分子+偏斜全超凡（花 100/165 点）裸血 6000→3064，撞 75% 帽有效血 24000→约 12260（全防御 build 从 4 倍裸怪压回约 2 倍）。战斗池剩余→伤害膨胀、机动池剩余→移速膨胀未接（另评）。

### 6.2 1024 血量上限 → 自定义血池（DECIDED / 实现红线）[红队]

原版 `generic.max_health` 钳制在 1024，而 6★ 起有效血量已破 1024。强制规范：

1. **单一权威血量来源**：6★ 及以上一律以自定义 `double currentHp / maxHp` 为权威。所有扣血、回血、百分比血修正、低血阈值（嗜血/命定）、拦死，统一只读写该池。
2. **vanilla 仅作渲染镜像**：每 tick `displayHealth = clamp(currentHp / maxHp × 实际属性上限, 0, 实际属性上限)` 同步。严禁业务逻辑读 vanilla `getHealth`/`max_health` 做判定。（2026-07-07 批2 修订：promoter 把血池怪 vanilla 血量属性设到有效血真值——测试服 AttributeFix 已把 max_health 上限抬到 1e6，属性真到位，Jade 等悬浮血条直显真血，恢复 Champions 时代观感；无 AttributeFix 环境属性自钳 1024，镜像按 `getMaxHealth()` 读回值等比映射自动降级。池仍是唯一战斗权威，此项纯显示层。）
3. **拦死单一判据**：`currentHp - 本次伤害 ≤ 0` → 主动 `entity.kill()`。
4. **回血池内 clamp**：`currentHp = min(currentHp + heal×dt, maxHp)`。
5. **TDD 强校验**：`test_flat_heal_no_overflow`（73000 满血回血 10s 恒 73000）、`test_kill_precise_at_zero`（204400 池 currentHp=1 不死 / =0 必死）、`test_lowhp_threshold_uses_pool`（mock vanilla=1024 断言阈值仍按池 %）、`test_no_lockhealth`（删"池≤0 则 kill"逻辑后 `test_kill_precise_at_zero` 必挂）。

## 九、架构与实现（DECIDED）

### 9.1 Champions 接入
- 1-10★ = 10 条自定义 rank（`champions-ranks.toml` 支持无限 rank）。
- 自定义词条走 `IAffixBase/IAffixCombatHandler/IAffixLifecycle/IAffixSyncable`（或 KubeJS 注册）。
- **接管 spawn 期词条分配**：不用原版随机 roller，按四池预算 + 互斥 + 品质解锁 + 软上限自行挑词条并定基础膨胀，再用其 API 盖章到怪物。**spawn 热路径不跑重型背包算法**：离线为每星预计算候选词条集模板，spawn 时抽模板（性能）。

### 9.2 净减伤单一拦截点（红线 1）
6★+ 血池的 `LivingHurtEvent` 与子弹的 `EntityHurtByGunEvent` 为同一受击结算点：求 `keep = ∏(1 - rᵢ)`（bullet_resistance + 复合同源适应层折率 + 偏斜 EV + 刚毅折算 + 缩小化体型折算），`keep = max(keep, 0.25)`（帽 75%，2026-07-07 随复合同源适应抬帽）。TDD：8★(子弹0.30+复合满0.65+偏斜0.25)、9★(重型0.49+复合满0.75+偏斜0.35+缩小化0.275) 对基准子弹最终伤害必须 ≥ 原始 ×0.25，删 clamp 必挂。

### 9.3 KnockbackSafetyGuard（红线 6）
所有产生位移/击退/击飞/换位的效果（凯撒/闪光/战术传送/灵体/利刃/反震/混沌/巨大化 blink）统一接入服务端权威守卫，**预测向量末端落点而非瞬间落点**：
- 落点向下连续扫描 ≥4 格无 `lava/flowing_lava/fire/magma_block/#fire`（虚空：落点至维度 `min_y` 间须有固体落脚面）；
- 水平距任何岩浆/虚空边缘 ≥2 格（以向下落脚柱为主防线，边缘检查 2-3 格；**严禁 8 格球形半径**——岩浆密布矿洞会使技能近乎永不触发 = 强度归零）；
- 末端为 hazard → clamp 击退分量到安全距离 或 仅结算伤害取消位移；
- 换位/瞬移后玩家获 **2.0s 抗位移落地保护**，覆盖原版近战击退 + 怪物体积推挤 + 所有位移词条（不止命名词条）；
- 禁止任何效果直接 `setDeltaMovement/push` 绕闸，写操作经 `server.execute` 回主线程。

### 9.4 形态守卫（巨大化/灵体）
- 巨大化：生成期按放大后 AABB 的 ceil 尺寸做碰撞箱-几何容纳校验，不容纳则降体型档（点数保持一致）或换同池等成本生存词条；运行时连续 2s 几何阻挡触发一次 blink（须容纳放大碰撞箱 + 玩家可达侧 + 禁落玩家 1 格内 + 内 CD ≥3s + 预兆）。
- 灵体移动实体化保底回退链（强制按序）：玩家可达且缰绳内最近合法空地 → lastValidPos → 强制脱离灵体态 +2s 眩晕（带行动窗口、高亮预兆）。禁塞墙/悬空孤儿。
- **生成约束（治本）**：禁止灵体移动出现在平均通道宽度 <2 格深层矿洞刷怪权重表；任何"威胁主要来自近战 on-hit 的传送家族怪"，生成时强制至少绑一条非近战可达的到达手段（点落地 AOE / 远程 on-hit）。

### 9.5 聚合器（红线 2/4/5）
- 每玩家控制聚合层：失明/击飞/位移进统一 DR；7s 滚动窗受控 ≤50% 且必有连续 ≥2s 自由窗。
- per-attacker 反伤秒窗累加器：所有反伤源累加 clamp ≤30% attacker maxHP/s + 单窗累计 ≤40%。
- DoT 聚合：同玩家所有 DoT 每秒合计 ≤15% maxHP，按贡献比例衰减。

### 9.6 TACZ 接入（已核实）
- 抗枪减伤走 `tacz:bullet_resistance` 属性（0-1，syncable，挂全实体），瞬态 AttributeModifier，封顶 <0.5 并入净减伤钳制。
- 公共事件可用：`GunShootEvent/GunFireEvent/EntityHurtByGunEvent/AttachmentPropertyEvent`；KubeJS。无需 mixin。
- 后坐力客户端独占，不做服务端修改（故"武器干扰"不走后坐力）。

### 9.7 表现层
所有技能类、蓄力、核弹、锁定、换位、灵体兜底必须有客户端特效 + 地面/头顶指示 + (处决/核弹) 警告音。

## 九·附 Champions 接入可行性与表现层审查（DECIDED；[审查]）

对照 Champions Unofficial 1.20.1 源（[PickAID/Champions](https://github.com/PickAID/Champions)）逐项核可行性。结论：除"服务端改玩家后坐力"（早已放弃）外，无真正做不到的功能。

### 9A.1 可用接入钩子（已核源）

- `IAffixCombatHandler`：`onAttack(champion,target,source,amount):boolean`（攻击目标，放行/取消）、`onHurt`/`onDamage(...):float`（改入伤，返回新伤害）、`onHeal(...):float`（改回血）、`onDeath(champion,source):boolean`（返 false 可拦死）
- `IAffixLifecycle`：`onInitialSpawn`/`onSpawn`/`onServerUpdate`（每 tick 服务端）/`onClientUpdate`（每 tick 客户端，高级特效入口）
- `IChampion`：`getLivingEntity()`、`getServer().setRank/setAffixes/getAffixes`、`getData/setData(CompoundTag)`（每怪状态存储）

### 9A.2 贯穿铁律（实现红线）

**Champions 只提供"单怪、单词条"钩子。** 所有封顶/聚合/跨玩家/血池/安全守卫红线**必须自建在 Forge 层**（一个统一受击 `LivingHurtEvent` 单点 + 一套玩家侧 capability），不得依赖 Champions 的逐词条钩子：

- **禁止用 Champions 逐词条 `onHurt` 实现减伤**：逐词条 onHurt 是串行 newAmount，无全局 clamp，多源相乘必穿透净减伤 49%（红队已证）。减伤一律走第 9.2 节单点聚合。
- 跨多怪、跨玩家的聚合（DoT 每秒≤15%、控制 7s 窗≤50%、反伤多源秒窗）Champions 数据是 per-champion，覆盖不到 → 全部落在玩家侧 capability（红线 4/5 + 红线 2 的 9.5 聚合器）。

### 9A.6 表现层原语工具箱与注意

服务端可发、纯原版客户端可见的原语（1.20.1）：
- 展示实体 `block_display`/`item_display`/`text_display`（1.19.4+）→ 地面光圈/落点/漂浮倒计时
- `ServerLevel.sendParticles` → 蓄力云/粒子环/连线/爆点
- `LightningBolt.setVisualOnly(true)` → 天雷雷击视觉
- `ServerBossEvent` → BOSS 血条（名/色/分段）
- `Glowing`（轮廓穿墙，记分板配色）→ 高亮目标
- `title`/`subtitle`/`actionbar` + 声音 → 警告/读条文字
- 高级打磨（自定义模型/着色器/全屏 HUD）才需我方客户端，走 Champions `onClientUpdate` 钩子；modpack 服（TACZ/Champions 已客户端必装）直接做

注意（实现纪律，非 blocker）：
1. **性能**：10 人世界 BOSS 多技能同跑，粒子/展示实体/封包须设数量预算上限，禁止每 tick 喷满。
2. **自定义音效**需资源包；兼容纯原版客户端则退用原版音效。
3. **唯一不可行**：服务端改后坐力（#19，已放弃）。

### 9A.7 词条品质显示（DECIDED）

精英怪的每个词条在显示时**必须带出其品质**（普通/中级/高级/超凡/闪耀），让玩家——尤其特勤干员探测——一眼看清"这条词条有多强"，而非只看到词条名。

- **配色**（MMO 稀有度梯度）：普通=灰白 / 中级=绿 / 高级=蓝 / 超凡=紫 / 闪耀=金（signature，可加微光），与塔罗 R/SR/SSR/UR/闪耀 体系视觉一致。
- **显示位置**：
  - 冠军头顶名牌：Champions 原生 rank 颜色 + 词条名/图标按品质着色；
  - 特勤干员探测词条列表（L7+）：逐条 `词条名 [品质]`，按品质着色；
  - 8★+ 世界 BOSS 血条下可附词条品质摘要。
- **数据**：品质已在词条实例上（spawn 时定），经 `IAffixSyncable` 同步客户端即可读取渲染，无需额外存储。
- **原版退路**：无我方客户端时，用名牌文本/`text_display` 以原版颜色代码（§-color）输出品质，纯原版客户端也能看出档位。
