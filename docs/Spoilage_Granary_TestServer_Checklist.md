## 3. 粮仓（建筑与权限）

| # | 项目 | 判据 |
| --- | --- | --- |
| 3.1 | 验收与档位 | 粮棚/冷库/官仓按验收人等级成立；验收后锁定不追溯 |
| 3.2 | 额度与启用 | 囤数上限按等级；可支撑囤数 = 室内格/9、气窗×4、冷源×2 取最小 |
| 3.3 | 停表 | 存满 24 小时才开始停表；跨整点先结算；取出后剩的时间与额度对得上 |
| 3.4 | 损坏与宽限 | 破洞/进水/冲突判整座损坏；宽限期（7 天 / 出事后首次上线 3 天，取较晚，上限 28 天）内照常停表 |
| 3.5 | 合建成员 | 房主能加/移成员；成员只能退出自己；房主拿不走别人的囤 |
| 3.6 | 待领粮单 | 退出/被移出/被拆走的囤进单子并占额度；领回后额度归还 |
| 3.7 | 开放名单 | 名单内「只存」能存不能取；「可存可取」都能；名单外连房主都拿不走 |
| 3.8 | 公开模式（官仓） | 只有官仓能开；陌生人按人按天限组；北京 08:00 翻日；降档后自动失效 |
| 3.9 | 流水 | 谁存谁取都留痕，每座粮仓最近 300 条，最新在前 |
