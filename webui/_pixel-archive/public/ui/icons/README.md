# 功能图标资产（程序生成的单色蒙版）

本目录的 24 张 PNG 是 **PixelUI 规格第八章第 2 层**的功能图标——MC 原版没有对应贴图、必须自绘的界面动作图标
（关闭、排序、筛选、刷新一类）。物品与方块图标**不在这里**，一律复用 MC 原版贴图走 `ItemIcon`。

真源规格：`docs/PixelUI_DesignSystem_DesignSpec.md` 第八章（图标）、6.1（单色蒙版上色）、4.4（资产规格）。
消费侧组件：`webui/src/components/pixel/PixelIcon.tsx`。

## 一、资产契约

| 项 | 取值 | 违反的后果 |
|---|---|---|
| 尺寸 | 16x16，1x 像素密度，**严禁美术端预放大** | 预放大把插值烘死进资产，后续再缩放必糊 |
| 格式 | PNG，8 位灰度 + alpha（colorType 4） | —— |
| 灰度 | **恒为 255**，不携带任何明暗与色相 | 灰度写 0 时若引擎按 luminance 解蒙版，图标整体消失且不报错 |
| alpha | **只有 0 与 255** 两种取值 | 中间值即抗锯齿，是硬红线 |
| 边距 | 主体四周留 **1px 空白**，不顶满画布 | 顶满时与相邻元素没有呼吸位，放大后边缘易被容器裁掉半格 |
| 笔画 | 不小于 2 像素宽；对角线走**阶梯**，不画 1 像素宽近似直线 | 纯对角线上的像素只在对角相接，观感是断续点列 |

**只有 alpha 有意义。** 颜色由 `PixelIcon` 的 `background-color: currentColor` + `mask-image` 给（规格 6.1 主路径），
因此 normal / hover / pressed 与 普通 / 强调 / 危险 **一律换色表达，不为任何状态增发第二张图**——
换色只要在父级写 `text-accent` / `text-danger`，不需要动资产。

## 二、图形的真源是字符矩阵，不是这些 PNG

所有图形以 16x16 字符矩阵（`'.'` 透明 / `'#'` 实心）写在 `webui/tools/gen-icons.mjs` 的 `ICONS` 表里，
PNG 由它生成。**要调形请改矩阵**：矩阵在编辑器里就是图本身，改哪个像素一目了然，而直接用图像编辑器
覆盖 PNG 会让两边脱节（下次重跑生成器就把手改的图覆盖掉）。

```
node tools/gen-icons.mjs          # 写盘并自检
node tools/gen-icons.mjs --check  # 只校验一致性, 不写盘, 不一致退出码 1
```

生成器零第三方依赖（`node:zlib` + 手写 PNG 分块），出图前后共六层机械自检：

1. 矩阵严格 16 行 x 16 列，且只含 `.` 与 `#`；
2. 最外一圈必须全透明（1px 边距）；
3. 每个实心像素在**上下左右**四邻域内至少有一个实心邻居——同时封死孤立单像素与 1 像素宽对角线；
4. 实心像素总数落在 [12, 140]——空图与实心方块都不是图标，而空蒙版渲染出来是**整块不可见且不报错**；
5. 对称与同构关系：一批图标校验左右／上下对称，四向箭头之间校验镜像与转置关系（四张箭头必须是同一个
   形状的四个朝向，否则并排放进分页器时头的大小、杆的长短各差一两像素，观感立刻散架）；
6. 灰度恒定、alpha 二值、PNG 往返解码与源像素逐字节相等。

另有一条跨文件校验：生成器会从 `PixelIcon.tsx` 解出 `PIXEL_ICON_NAMES`，与图标表**双向比对**。
出了图而组件没登记＝那张图永远不会被打包引用；组件登记了而没出图＝构建期 `import` 直接炸。
解不出名单时脚本直接失败，不退化成静默跳过。

确定性：同一 Node（同 zlib）下同输入必得同字节，反复重跑不产生 git 噪声。跨 Node 大版本不作此保证——
DEFLATE 允许多种合法编码，此时 `--check` 报 STALE，重跑写盘即可；正确性的真判据是上面六层自检。

## 三、美术替换规则

按同尺寸（16x16）、同名覆盖即可，前端零改动——但覆盖前请先把新形状写回 `gen-icons.mjs` 的矩阵表
（见第二节）。若确实要脱离生成器改为纯手绘资产，删掉生成器时必须同时把上述六层自检搬到
`scripts/verify-pixel-guards.mjs`，否则 alpha 二值性与 1px 边距这两条就再没有人守。

新增图标需要三处同步：矩阵表（`gen-icons.mjs`）、`PIXEL_ICON_NAMES` 与 `PIXEL_ICON_SOURCES`
（`PixelIcon.tsx`，后者由 `Record<PixelIconName, string>` 的类型在 tsc 阶段强制补全）。漏掉任何一处都会被
生成器的跨文件校验或 tsc 拦住。

构建期尺寸守卫已覆盖本目录：`scripts/verify-pixel-guards.mjs` 递归扫描 `public`，要求每张 PNG 边长在
16/24 白名单内且能完整解码（走完 PNG 分块并逐块校验 CRC）。
