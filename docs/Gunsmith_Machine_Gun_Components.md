# 机枪平台组件规格

> 状态：文档规格与本地化已登记；不代表已有机枪图纸、成品枪、配方或可获取物品。
> 关联文档：[枪匠组件命名计划](Gunsmith_Component_Naming_Plan.md)、[枪匠组件平衡与后续扩展路线](Gunsmith_Component_Balance_Roadmap.md)、[军火商职业设计规格](Munitions_Job_DesignSpec.md)。

## 一、平台登记

| 平台标识 | index | 本地化显示 |
|---|---:|---|
| `MACHINE_GUN` | 6 | 机枪 / Machine Gun |

本平台只记录组件槽位与属性映射，不虚构对应的枪械图纸或成品枪。

## 二、组件顺序

机枪平台组件按以下顺序记录：

1. `HANDGUARD`
2. `BOLT`
3. `BARREL`
4. `STOCK`
5. `BIPOD`

对应的基础组件本地化名称为基础护木、基础枪机、基础枪管、基础枪托、基础脚架。

## 三、品质档位

所有五类基础组件使用以下五档品质：

1. 普通 / Common
2. 改良 / Improved
3. 军规 / Mil-Spec
4. 精密 / Precision
5. 传奇 / Legendary

## 四、CMD 范围

| 组件 | CMD 范围 |
|---|---:|
| `BARREL` | 611-615 |
| `BOLT` | 621-625 |
| `HANDGUARD` | 631-635 |
| `STOCK` | 651-655 |
| `BIPOD` | 701-705 |

每个范围按普通、改良、军规、精密、传奇顺序对应五档品质。

## 五、属性映射

| 组件 | 基础属性 |
|---|---|
| `BOLT` | 伤害 |
| `BARREL` | 爆头 |
| `STOCK` | 后坐 |
| `HANDGUARD` | 散布 |
| `BIPOD` | 操控 |
| 平台固定项 | `range = 1.0` |

机枪平台基础组件不修改射速。`+30%`、`+60%`、特殊导气以及任何惩罚数值仍只是平衡讨论中的说明性例子，不是本规格的定案值。

## 六、图纸与 TaCZ 绑定边界

当前不新增或虚构机枪图纸、成品枪、配方、掉落或可获取物品。后续只有在绑定实际 TaCZ 枪械时，才按已确认的源枪数据接入；装配结果必须保留源枪原有的完整、有序射击模式列表，不得默认改成半自动，也不得删除、追加或重排模式。
