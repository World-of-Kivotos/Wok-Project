# 格赫娜高速导气组件规格

> 状态：首个特殊枪匠组件已进入实现。关联边界见[枪匠组件平衡与后续扩展路线](Gunsmith_Component_Balance_Roadmap.md)。

## 一、组件身份

- 稳定变体 ID：`gehenna_gas`（`gehenna_high_speed_gas` 只是存量物品迁移用的历史别名，不是合法的 datapack 规则文件名，用它命名的覆盖文件会被忽略并只在日志留 ERROR；见 `GunsmithPartVariant`、`GunsmithComponentRuleLoader`）
- 显示名：`格赫娜高速导气`
- 适用平台：仅 `AR`
- 装配槽位：`CORE`（导气）
- 品质：继续使用普通、改良、军规、精密、传奇五档及单件浮动系数
- 制造入口：机械冲压机的“AR / 导气 / 组件类型”选择

该组件是独立 `variant`，不得覆盖或改名冒充 `basic` 基础导气。旧零件和旧成枪数据缺少变体字段时，只按旧版本迁移为 `basic`。

## 二、说明文本

由格赫娜万魔殿研发的新型高速导气组件。它通过提升导气效率加快枪机循环，从而显著提高枪械射速；但过快的循环超出了缓冲机构的控制范围，不仅令连续射击时的上跳后坐力大幅增加，也会扩大弹道散布、降低射击精度。

## 三、属性规则

### 3.1 射速

该组件的半自动与全自动循环射速按品质档位查表，单件浮动系数不参与射速计算：

| 品质 | 射速乘区 |
|---|---:|
| 普通 | ×1.05 |
| 改良 | ×1.10 |
| 军规 | ×1.15 |
| 精密 | ×1.20 |
| 传奇 | ×1.25 |

数值真源是 datapack 组件规则文件 `data/miningdim/gunsmith/components/gehenna_gas.json` 的 `fire_rate` 字段，可热更新（流程见[枪匠特殊组件热更新规则](Gunsmith_Component_Hot_Reload_Rules.md)）。普通档的下限即 `+5%`，不存在 `+0%` 档。

浮动系数与射速是两套互不相通的计算路径：浮动系数（`GunsmithStat` 的品质系数体系）只参与伤害、爆头、射程、后坐、散布、操控六项基础属性的推导，射速只由 `VariantStat.FIRE_RATE` 按品质查组件规则表得出，两者不互相插值。

TaCZ 1.1.8 的三连发内部节奏不读取 `ROUNDS_PER_MINUTE` 属性缓存，因此本组件不改变 `burst_data` 的内部 BPM 或两轮三连发之间的最小间隔。界面和 tooltip 不得宣称三连发内部节奏已经加速，也不得改动、删除或重排源枪的射击模式。

### 3.2 后坐力

- 该组件施加**全向**后坐惩罚：普通、改良、军规、精密、传奇五档恒为 `×2.00`，上跳（pitch）与水平（yaw）同时生效且倍率相同。
- 不额外施加垂直专属倍率（规则文件的 `vertical_recoil` 五档恒为 `1.00`）。
- 与 3.1 节的射速不同，也与浮动系数无关：该惩罚是离散定值，不随单件浮动系数连续插值。
- 枪托提供的基础后坐力系数仍同时作用于 pitch 与 yaw；最终 pitch 与最终 yaw 均为“枪托后坐倍率 × 2.00”。
- 数值真源同为 `data/miningdim/gunsmith/components/gehenna_gas.json` 的 `recoil` / `vertical_recoil` 字段。

### 3.3 散布

- 该组件按品质档位扩大实际弹道散布，不随单件浮动系数变化：

| 品质 | 散布乘区 | 界面显示 |
|---|---:|---|
| 普通 | ×1.03 | `散布 +3.0%` |
| 改良 | ×1.06 | `散布 +6.0%` |
| 军规 | ×1.09 | `散布 +9.0%` |
| 精密 | ×1.12 | `散布 +12.0%` |
| 传奇 | ×1.15 | `散布 +15.0%` |

```text
最终散布乘区 = (1 / 护木散布系数) * 格赫娜散布乘区
```

- 散布乘区越大代表精度越差，界面和 tooltip 必须标为负面效果；品质越高惩罚越重，这是射速表同向递增所付的代价，调平衡时两张表要一起看。
- 数值真源是 `data/miningdim/gunsmith/components/gehenna_gas.json` 的 `spread` 字段，与[枪匠特殊组件热更新规则](Gunsmith_Component_Hot_Reload_Rules.md)第五节的当前表为同一份数据。
- 枪械装配预览与成品 tooltip 显示该惩罚和护木散布控制共同结算后的最终散布变化，不得把组件自身的档位百分比直接冒充整枪最终值。

### 3.4 有效射程

格赫娜高速导气自身**不额外提供射程倍率**：规则文件的 `effective_range` 取 `operation = multiply`、五档 `values` 全为 `1.0`，避免在已批准的射速、后坐力和散布变化之外再增加额外收益。

但这**不等于**该槽位对整枪射程的贡献被锁成固定 `1.0`。装配属性计算（`GunsmithGunStats.range()`）先取 `CORE` 槽的品质浮动系数，再依次乘各组件的射程倍率，因此装了格赫娜导气的 AR，其最终有效射程仍随这件导气自身的品质浮动系数放大——例如传奇档浮动系数区间 `1.36-1.50`，中点约 `1.43`。

若产品意图确实是把最终射程锁成与品质无关的固定值，必须把 `gehenna_gas.json` 的 `effective_range.operation` 改为 `replace` 并给出期望的固定倍率，同时更新 `GunsmithStatGameTests` 的相关期望值，而不是只改本文描述。

## 四、制造与界面

材料仍沿用 `CORE` 槽位的三种基础材料，再按品质材料倍率和制作时间计算；材料侧不按稀有度加价。

但本组件属**特种级**稀有度（`GunsmithPartRarity.SPECIAL`），冲压时另受两道稀有度约束，唯一权威判定在服务端冲压结算（`GunsmithPressBlockEntity`），界面只做提前提示：

- 等级门 `[gunsmith] rarityUnlockSpecial`（默认 `6`）：军火商等级不足直接拒绝冲压。
- 工费倍率 `[gunsmith] pressRarityFeeMultiplierSpecial`（默认 `2.5`）：实扣 = `ceil(pressWorkFeeCredits × 品质材料倍率 × 2.5)`。

两项数值与分级依据见[枪匠组件命名计划](Gunsmith_Component_Naming_Plan.md)第 5.1 节。后续经济评审如调整获取来源，必须单独修改规格、成本和测试。

制造界面必须同时显示：

- 当前组件类型和品质。
- 该件成品按品质查表得到的实际射速百分比，而不只显示通用浮动系数。
- 该件成品的全向后坐力百分比（五档恒为 `+100%`）。
- 该品质档对应的散布惩罚百分比（普通 `+3.0%` 至传奇 `+15.0%`），并以负面颜色明确提示精度下降。
- 当前材料数量与所需数量。

装配预览与成品枪 tooltip 必须显示最终射速、最终后坐力和最终散布变化。

## 五、数据与兼容

- 新零件写入显式零件数据版本与 `GunsmithVariant`。
- 新成枪数据版本为 **v7**（`GunsmithGunStats.CURRENT_VERSION`），每个已装组件显式保存 `variant`、品质与原始浮动系数；只有 `CURRENT_VERSION` 的缓存才与当前公式逐项精确比对，更旧的版本一律只验类型与值域。
- 本文不再单独维护一份版本号叙述：v1/v2 读取为全 `basic`、v4 MK-AX-A 机匣回枪机、v5 补兼容握把、v6 补兼容撞针等现行迁移链，统一以[枪匠特殊组件热更新规则](Gunsmith_Component_Hot_Reload_Rules.md)第十二节（存量枪兼容）为准，避免两份文档各写一套版本号再次漂移。
- 历史上曾先后使用过 `+40%`、`+100%`、最高 `+300%` 三条上跳后坐曲线与固定 `+30%` 散布惩罚；这些只是旧版本的迁移语境，**不是当前公式的一部分**。当前目标曲线已改为 3.2、3.3 两节描述的离散定值表（全向后坐恒 `×2.00`、散布按品质 `×1.03`-`×1.15`），且特殊组件的动态倍率在读取枪械时从当前规则快照实时计算，不依赖缓存里的旧值。
- 非 AR、非导气槽使用 `gehenna_gas` 必须明确拒绝。

## 六、验收

- 五个品质档逐档断言射速乘区（`1.05` / `1.10` / `1.15` / `1.20` / `1.25`）与散布乘区（`1.03` / `1.06` / `1.09` / `1.12` / `1.15`），两张表都不随单件浮动系数变化。
- 特殊导气自身的射程倍率恒为 `1.0`（不额外放大或缩小射程），但该槽位最终射程仍随该件品质浮动系数变化。
- 五个品质档的全向后坐力乘区恒为 `2.00`（pitch 与 yaw 相同），额外垂直后坐乘区恒为 `1.00`，均不随单件浮动系数变化。
- 最终散布乘区 = `(1 / 护木散布系数) × 该品质档散布乘区`，与护木散布控制共同结算。
- RPM 使用最终缓存值乘射速乘区并按 TaCZ 规则四舍五入为整数。
- 旧零件和 v1/v2 成枪兼容为 `basic`，其余存量成枪按[枪匠特殊组件热更新规则](Gunsmith_Component_Hot_Reload_Rules.md)第十二节的迁移链读取，并在读取后按当前规则快照实时计算后坐与散布。
- 冲压选择、产物 NBT、装配预览、成枪 NBT、tooltip 和 TaCZ 实战缓存一致。
- 源枪射击模式列表及顺序保持不变。
