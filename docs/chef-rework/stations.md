# 烹饪台方案（草案）

> 2026-10-10。204 道菜里，92 道在农夫乐事厨锅做，7 道是厨锅盛宴，1 道是厨锅 + 炼药锅，剩下 **104 道不在厨锅里做**。
> 用户决定：给这 104 道新做烹饪台，第一个做**炸锅**（从建模开始，先出预览）。

## 按做法分组

| 台子 | 菜数 | 包含 |
|---|---|---|
| 农夫乐事厨锅（已有） | 100 | 汤、炖菜、饭、面、水饺、厨锅盛宴 |
| **炸锅**（新做，取代随性乐事的炸锅） | 4（另可迁入 5） | 大炸饺、春卷、盘装大炸饺、春卷拼盘；可从厨锅迁入：炸鱼薯条、鱿鱼圈、炸蟹角、恩潘纳达炸饺、蜂蜜炸海带 |
| **烤炉**（新做） | 36 | 派与蛋糕（巴克拉瓦、乳蛋饼、披萨、洛林乳蛋饼、仰望星空派、大树莓派、巧克力派、苹果派、蛋糕、南瓜派、甜浆果芝士派、牧羊人派）、烤肉（烤鸡、蜜汁火腿、烤羊排、牛排配土豆、香烤鲑鱼）、曲奇与吐司（4 种曲奇、6 种吐司 / 烤面包、烤棉花糖饼干、甜瓜面包、驴肉火烧）、烤串（烧烤串、鱿鱼烤串、烤虾串、青蛙腿烤串、烤面筋、填馅鳕鱼） |
| **备餐台**（新做） | 52 | 汉堡 8、卷饼 / 塔可 5、三明治与吐司拼盘 12、寿司与饭团 13 + 3 个拼盘、沙拉与冷盘 11 |
| **冷饮**（并进备餐台，或单独做冷饮机） | 12 | 抹茶 / 浆果拿铁、冰淇淋 2、奶昔 2、绿舌头雪糕、3 种冰棍、海泡菜汁、海带汁、西瓜汁 |

## 建议

- 最少 **3 台新台子**：炸锅、烤炉、备餐台（冷饮先并进备餐台）。如果想要更多厨房味，再把冷饮拆成第 4 台“冷饮机”。
- 所有台子共用同一套“掌勺”小游戏内核（星露谷钓鱼条），各台只换皮和规则：
  - 炸锅：油温条；
  - 烤炉：火候 + 翻面；
  - 备餐台：摆盘节奏。
- 迁移方式：数据包覆盖原配方，把这 104 道菜的工作台 / 营火 / 随性乐事炸锅配方，改成对应台子的配方类型。非厨师照样能用这些台子，做出来的是家常菜（不走小游戏，没有厨师效果）。
- 随性乐事自带的炸锅：配方迁走以后，把它本身的合成配方删掉，避免玩家拿它绕开厨师。
