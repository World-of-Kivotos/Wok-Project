# 厨师重构设计资料（2026-10）

厨师职业重构已经拍板的设计。代码目前只落地了九台烹饪台方块（`com.miningdim.job.chef.station`），其余部分按这里的规格分批实现。

| 文件 | 内容 |
|---|---|
| `effect-pool.md` | 41 个厨师效果（战斗 14 / 探索 13 / 增益 14）的七档数值、上限、PvP 测算、家常菜原效果微调表、实现方式；第 ⑧ 节是拍板记录 |
| `dish-stars.md` / `.tsv` | 204 道菜按食材获取难度的 ★1–★7 评级和计分明细 |
| `dish-effects.md` / `.tsv` | 每道菜固定的厨师效果，以及五档品质各给什么（同一效果、同一数值，只差时长） |
| `stations.md` | 非厨锅菜分到哪台烹饪台（炸锅 / 烤炉 / 备餐台） |
| `minigame-spec.md` | “掌勺”小游戏规格 v2：内核规则、四台附加规则、难度表、品质判定、服务端回放校验、调参与审查记录 |

核心规则：一道菜固定一个厨师效果，星级决定数值，品质只决定时长（低 3 分 / 中 8 分 / 高 15 分 / 超凡 30 分 / 闪耀 = 单命永久）。每个大类同时最多 1 个永久 + 2 个限时；盛宴只有第一份能出永久。

相关工具：

- `tools/chef_stations/`：九台烹饪台的造型预览与生成器（原版方块模型 + 16×16 贴图），用法见其中的 `README.txt`。
- `tools/chef_minigame/`：掌勺小游戏的确定性内核（`sim/sim.js`，JS 与 Java 逐位一致）、机器人平衡仿真、Java 移植参考与金样本、网页试玩原型的源码。
