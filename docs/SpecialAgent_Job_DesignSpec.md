# 特勤干员 职业设计规格（SpecialAgent Job）

> 状态标记：DECIDED = 已拍板；PENDING = 待定。
> 平台：Forge 1.20.1 / Forge 47.x / Java 17。modid：`miningdim`。
> 前置真源：[JobFramework_Shared_Foundation_DesignSpec.md](JobFramework_Shared_Foundation_DesignSpec.md)（统一进度/升级/经济/menu 地基）、[ChampionStarAffix_System_DesignSpec.md](ChampionStarAffix_System_DesignSpec.md)（精英怪星级词条体系，本职业深度联动）、[服务器经济系统设计文档.md](服务器经济系统设计文档.md)（信用点/青辉石/盖章/产出闸）。
> 设计哲学：与本项目所有职业一致，走 FF14 生产职业路线——**主打经济产出，战斗仅少量加成**，不做战力核心。

---

## 一、概述与定位（DECIDED）

特勤干员是一个**服务于 PVE 的经济/情报职业**：玩家通过**寻找精英怪 → 扫描情报 → 参与击杀 → 完成悬赏**赚取信用点（周常额外少量青辉石）。它不是战术 buff 位、也不是 DPS 位，而是"把恶心的精英变得可打、并靠找得多/看得透/打得准来赚钱"的个人经济职。

三大特色能力：

- **探测（战术扫描）**：渐进式情报扫描，等级越高把精英看得越透——核心经济引擎。
- **封印**：临时压制精英的少量词条，让自己这一仗打得动；绝不永久削废。
- **悬赏 + 击杀经济**：每日/周常悬赏 + 击杀精英的贡献分赃 + 加强奖励。

职业等级 1-10，与精英星级同尺度（L 级 ≈ 能应对 N★），便于门控对齐。

---

## 二、与精英怪体系的联动（核心闭环，DECIDED）

精英怪体系负责"出题"（精英带恶心词条），特勤干员负责"解题"（找到、看清、临时去爪牙）。这是本职业的存在价值：带一个高级干员打世界 BOSS，能短暂封掉它的命定之死/小男孩，团队压力骤降。

闭环：**探测找到目标 → 扫描看清词条/威胁 → 1 个封印槽花在刀刃上开窗口 → 趁窗口打出贡献 → 按贡献从固定池分钱 + 完成悬赏**。

---

## 三、奖励模型：贡献池分赃（DECIDED）

为同时消除**抢怪、蹭枪、叠叠乐**三个问题，精英奖励一律走"固定池 + 伤害贡献占比瓜分"：

1. **固定奖励总池**：每只精英一个池，大小由它**出生盖章的初始星级**决定（即使被封印削弱也不变——封印不影响"值多少钱"）。
2. **按合格贡献者的伤害占比瓜分**（占比加权，非领奖台排名）：`份额 = 池 × 个人伤害 / 合格总伤害`。占比制让合作严格更优、无 denial 动机；可附最高贡献者一个小幅 top bonus（量级 PENDING）。**严禁按人头复制**。
3. **入池门槛（防蹭枪）**：个人贡献需 ≥ 该精英总有效血的 **0.5%** 才进分配，一发枪蹭不进。
4. **掉线作废回池**：死亡结算时不在线的贡献者，其份额作废、回池重分给在场合格者。
5. **封印不计贡献**（纯伤害论）：封印不是伤害，封了也得自己打才分得到钱——防"封一下就躺分"的恶意蹭怪。

伤害账本挂在精英体系的**单一受击拦截点**（见 ChampionStarAffix 9.2 净减伤单点）：每次受击按攻击者累计"减伤后实际伤害"，死亡时读账本结算。

| 4 | 全被动词条+护甲/减伤% · 160 | 被动≤4★·9s | ×1.75 | 日2 + 周1（青辉石解锁）· ≤4★ | +8% |

## 五、探测支线：战术扫描面板（DECIDED）

唯一情报载体是**一个面板**（不走聊天栏，避免高级后信息太多 UI 堆叠）。每次扫描脉冲按等级把这只精英的数据"逐格解密"，未解锁字段显示"加密/未解析"。

- **只给原始数据，不给弱点结论**：面板呈现词条/品质/数值，"怕火/怕狙"由玩家自己研究。
- **词条品质显示**：每条词条带品质色标（普通灰白/中级绿/高级蓝/超凡紫/闪耀金，见 ChampionStarAffix 9A.7）。
- **范围**作为副线随级涨（64 格 → 跨区块），主线是"看得多透"。
- **悬赏雷达**（L6）：面板顶部标注是否当前悬赏目标。
- **实时透视**（L9+）：当前血量/护盾/寒霜层数/技能 CD 实时刷新；L10 全属性实时。
- **Glowing 高亮**（L8）：用原版发光，穿墙可见。

形式：主动脉冲带长 CD（60s → 30s 随级缩），防全图刷新。

## 六、封印支线（DECIDED）

干员唯一的战斗向工具，且高度克制——只为"让你这一仗打得动"，不为"把 Boss 变废"。

- **临时**：有时长 + CD（被动 8s→12s、机制 3s→5s；CD 见总表），时间一到词条恢复。
- **少量**：同时 1 槽（L9 起 2 槽，仅高星用得上）。
- **每精英 1 槽（8★+ 为 2），先到先得**：多干员压一只也加不上更多封印 → 防叠叠乐。
- **类型/星级门控**：被动词条 L3 起可封；机制/核心类（命定之死/小男孩/天雷等）**仅 L8+ 可短暂封印、绝不永久移除**；可封星级随级抬到 10★。
- **封印只压"词条效果"，不动"基础膨胀"**：精英的基础血量/移速等基础数值封不掉——你只开窗口，不削废。
- **交互**：在扫描面板内**点击已解密的词条**即封印（探测与封印合一）。未解密的词条点不了——天然耦合"扫得透才封得到"。点击后该行变灰 + 恢复倒计时，封印进 CD。校验失败给原因提示（需更高等级 / 槽已占 / CD 中）。

## 七、加强奖励 / 日常周常权限 / 伤害加成（DECIDED）

### 7.1 加强奖励（额外击杀信用点）
- **击杀精英怪本身额外给你个人信用点**——与悬赏奖励无关、**不含青辉石**。
- 数值：`额外信用点 = f(初始星级) × 加强奖励系数（×1.0 → ×3.0）`，绝对底值随星级、留经济 config。
- **从池外给的个人 faucet**：不挤占他人贡献占比；**受经济每日软上限约束**（防印钞），并入 `EconomyConstants economy.daily.*` + AbuseGuard mob-kill faucet。

### 7.2 日常周常权限
- 悬赏槽位：日 1→5、周 0→3（周常 L4 解锁）。
- 可接悬赏星级随级抬到 ≤10★；L8 起开放世界 BOSS 悬赏。
- **青辉石仅来自周常悬赏**（≥L4），单设日产软上限。

### 7.3 伤害加成
- 仅对**精英/冠军怪** +5% → +15%（线性，随级 +1%）。纯帮干员够到入池门槛，**不做战力核心**（FF14 哲学）。

## 八、升级线（DECIDED）

### 8.1 XP 来源（贴合"找→扫→杀→悬赏"循环）

| 来源 | XP（示例·可调） | 说明 |
|---|---|---|
| 首次扫描发现精英 | 星级 × 8（1★=8 … 10★=80） | 每只仅首次，奖励"找"，防重复扫刷 |
| 击杀精英（达入池门槛） | 星级 × 60 × 你的贡献占比 | 主力来源，和分赃同口径 |
| 完成日常悬赏 | 400 ~ 1,500（随目标星级） | 结构化稳定来源 |
| 完成周常悬赏 | 2,500 ~ 6,000（随星级） | 大块，每周一次 |

### 8.2 1-10 级 XP 曲线（总量沿用框架 61,900）

| 级 | 本级需 XP | 累计 XP |
|---|---|---|
| 1→2 | 1,500 | 1,500 |
| 2→3 | 2,400 | 3,900 |
| 3→4 | 3,500 | 7,400 |
| 4→5 | 4,800 | 12,200 |
| 5→6 | 6,300 | 18,500 |
| 6→7 | 8,000 | 26,500 |
| 7→8 | 9,900 | 36,400 |
| 8→9 | 12,000 | 48,400 |
| 9→10 | 13,500 | 61,900 |

曲线前缓后陡：L3 解锁封印、L4 解锁周常来得快，后段越来越肝，对应"越高级越能碰世界 BOSS"。

### 8.3 每日软上限 + 衰减（防爆肝）

每日前 **2,000 XP 全额**；超出后按框架 `decayBase` 逐段几何衰减，趋向 **10% 地板**；UTC 翻日重置。满级天数（已用脚本核算，地板 10%）：

| 玩家类型 | 日 XP 产能 | 有效/日 | 满级约 |
|---|---|---|---|
| 休闲 | 2,000 | 2,000 | 31 天 |
| 正常 | 4,000 | 2,200 | 28 天 |
| 肝 | 7,000 | 2,500 | 25 天 |
| 肝满 | 12,000 | 3,000 | 21 天 |

约一个月满级；衰减调高后，爆肝边际显著递减（肝满也要 21 天，最多省约 1/3）。

### 8.4 升级即解锁
每升一级 = 解锁第四章总表对应行（探测情报变深、封印抬星、加强奖励系数升、权限开槽位/世界BOSS悬赏、伤害 +1%）。无空级。

## 九、防叠叠乐与公平不变量（DECIDED）

- 奖励 = 固定池（初始星级）按伤害贡献占比瓜分；**绝不按人头复制**。
- 加强奖励是**个人 faucet 额外信用点**，从池外给、不挤占他人占比、受日软上限。
- 封印**每精英 1 槽**（8★+ 2）、机制类只临时、**不可永久削废**。
- 伤害加成只少量、仅对 champion；**不存在任何"抬高自身贡献占比"的被动**（战斗加成是真实伤害，合法）。
- 青辉石仅周常产出（≥L4）。

## 十、架构与实现（DECIDED）

### 10.1 探测/扫描
- 维护我方 Champion 索引（`EntityJoinLevelEvent` + `IChampion` capability 检测 / `onInitialSpawn` 注册）。
- 扫描脉冲：按干员等级把该精英的 星级/词条/品质/血池/属性/技能CD（全是我们自己存的 `getData` + 词条实例）**分级推送**到干员客户端面板。
- 高亮走原版 `Glowing`（穿墙可见）。

### 10.2 封印
- 封印 = 在 `IChampion.getData/setData` 写"sealed 集合"；我方所有词条钩子（onServerUpdate/onAttack/onHurt）生效前先判 sealed → 因为 35 个词条都是我们自己写的，加判定即可临时压制。
- 对**施加了常驻 AttributeModifier 的词条**（如超高分子的 `tacz:bullet_resistance`），封印时按固定 UUID 撤掉修饰、解封时重加（Champions 无 `onRemove` 钩子，teardown 自写）。
- 计时到期恢复；`IAffixSyncable` 重同步客户端使面板/名牌刷新。

### 10.3 贡献账本与分赃
- 账本挂 ChampionStarAffix 9.2 的**单一受击拦截点**：`playerUUID → 累计减伤后伤害`（枪伤走 TACZ `EntityHurtByGunEvent` attacker、DoT 走伤害源 owner）。
- `onDeath`/`LivingDeathEvent` 读账本 → 入池门槛过滤 → 占比瓜分 → 掉线作废回池 → `IEconomyService.grant`。
- 加强奖励在结算时对达门槛的干员额外发个人信用点（受日软上限）。

### 10.4 面板 UI
- 自定义 Screen / 容器式 menu（走 JobFramework 公共 menu 脚手架，支持非方块菜单）；点击词条 → 服务端封印封包。需我方客户端（modpack 服可行；无 mod 时退结构化 `text_display`/名牌 + 原版颜色码）。

### 10.5 悬赏
- 每日/周常悬赏 = 个人任务清单；目标按星级/词条生成；完成判定走击杀盖章 + 入池门槛；UTC 翻日 + ISO 周重置；悬赏板用公共 menu。

## 十一、货币与经济接入（DECIDED）

- **信用点**三来源：① 通用贡献池（人人按伤害分）② 加强奖励（击杀精英额外个人）③ 悬赏。均经 `IEconomyService.grant`，并入经济每日软上限 + faucet。
- **青辉石**唯一来源：周常悬赏（≥L4），单设日产软上限。**注意：本条与代码现状不符**——`ChampionRewardHandler` 的 6★+ 掉落（2→10，随星级 +2）当前是活的产出口，一直在发。两者必须对齐，见十二章第 4 条。
- 沿用经济红队条款：盖章双门槛、召唤物 `summonedByAffix` 不计结算、固定池加权瓜分严禁按人头复制。
