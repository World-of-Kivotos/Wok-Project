# 社交平板存储与七天保留

适用 WOK 本体 `miningdim` 的 `wok-social` 模块。维护者于 2026-10-21 确认采用 SQLite 后台增量写入，并对世界聊天、私聊、说说和评论逐条保留七天；好友关系与已解锁主题长期保留。

## 保存与查询

- 每个世界独立使用根目录下的 `wok_social.db`。复用本体已内嵌的 sqlite-jdbc 3.45.3.0，不与市场、开箱共用数据表或连接。
- 单个后台线程每 100 毫秒收集最多 128 个操作，以事务写入变动记录。一次点赞只更新对应动态，一条评论或聊天单独追加，不重写整份社交存档。
- 使用 WAL 与 `synchronous=FULL`；后台队列有容量限制，积压满时在改变业务状态前返回 `SOCIAL_STORAGE_BUSY`。写入异常记录完整堆栈、保留未确认队列并拒绝后续操作，不假装保存成功。
- 正常关服等待待写队列提交，然后关闭连接。异常终止仍可能丢失尚在内存队列中的操作；不能把 WebUI 操作回执视为已经完成磁盘持久化的证明。
- 服务器线程保留档案和好友关系。历史查询按索引限量读取，不加载全部七天历史；新记录在后台提交前也可立即读取。磁盘读取不承诺完全脱离服务器线程，大型服仍需实际容量与延迟验证。
- 聊天同毫秒的先后顺序由持久化写入次序保持。动态按 `(createdAt,id)` 倒序分页，客户端续页同时提交 `before` 与 `beforeId`，避免同毫秒发帖漏项。

## 过期规则

- 活跃存档中的消息、动态与评论以各自 `createdAt` 为准，满七天（168 小时）即不再查询返回。
- 后台发现过期记录后，每次最多删除 128 条；没有积压时每分钟检查一次。好友、好友请求、玩家档案和已解锁主题不参与过期删除。
- 动态过期后不会再展示其讨论；评论有独立记录和时间戳，按评论自身七天期限删除。
- 原来的 100 条世界聊天、每会话 200 条私聊和 300 条动态不再作为磁盘删除上限；界面仍按原先的限量窗口及分页取数。
- 删除后的数据库页会供后续写入复用，数据库文件可能保留历史高水位。本模块不在服务器线程执行全库 `VACUUM`。

## 旧存档迁移

1. 首次加载时读取 `wok_social.json`，先创建字节一致的 `.migration-backup-<时间戳>` 副本，原文件保持不变。
2. 旧档案、好友关系、动态、独立评论、世界聊天与私聊在同一事务中导入，再写入数据库格式标记。旧 JSON 没有评论 ID，迁移时为每条评论生成稳定 ID。
3. 已初始化数据库后，不再导入旧 JSON，避免重启时重复添加或回灌已经过期的记录。
4. JSON 损坏、备份失败或导入失败时直接停止加载，不用空档覆盖。损坏 JSON 的恢复副本尽力写为 `.corrupt-<时间戳>`；备份失败会与原始错误一起记录，原件保留。

好友、收到请求和发出请求的关系拥有者及成员 UUID 在迁移前校验；错误包含字段、拥有者和所在位置。坏关系不进入数据库、不写迁移完成标记，源 JSON 保留。正常查询不再跳过非法 UUID。

迁移备份用于人工恢复，不自动按七天清理。备份正在运行的 SQLite 时须使用支持 SQLite 在线备份的工具，或正常停服后备份数据库；不能只复制正在写入的 `.db` 而忽略 WAL。

## 客户端与验证

默认打开键改为键盘 `~` 所在的反引号键（GLFW `GRAVE_ACCENT`），无需按 Shift；已有玩家自定义键位保留。点赞、评论分别沿用一秒玩家冷却，登出时清理冷却记录。

回执按实际 JSON 编码后的长度遵守原网络上限；聊天优先保留最新消息，动态保留可继续翻页的前缀。固定档案/好友字段过大时明确报错，不静默隐藏好友。

`SocialDatabaseGameTests` 的五项用例覆盖迁移、坏关系 UUID 拒绝与损坏保护、七天边界与分批清理、超旧数量上限的持久化与即时读取；`SocialActionsResponseSizeGameTests` 的四项回执用例覆盖编码膨胀与同毫秒分页，另有一项好友解析回归验证原样离线 UUID 与不存在的名字拒绝。

离线服加好友优先使用通过登录门的在线玩家身份；离线目标按输入名字的原样大小写派生 UUID，只有对应玩家存档存在时才接受。离线服不调用会创建虚构档案并访问 Mojang 的用户名缓存。正版模式保持既有缓存查询。

本轮删除无真实来源的好友统计、推荐及演示数据；starlight 主题默认解锁，已有主题选择与解锁存档保留。

本轮审查修复使用 JDK 17 和工程 Gradle Wrapper，通过 `compileJava`、`verifyModuleBoundaries`；完整 Forge GameTest 日志明确出现 `All 2123 required tests passed`。内联 JS 语法解析及直接 DOM ID 引用检查通过，七张大型内嵌图片保持一致。这些结果不能替代 MCEF 实机与大型服负载验收。
