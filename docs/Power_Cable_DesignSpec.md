# 电力线材系统 Mod — 设计规格文档

## 文档元信息

- 用途: 电力"线材(导体/线缆)"子系统实现阶段的唯一架构与机制参考。所有规则以本文档为准, 不得凭记忆改写。
- 目标平台: Minecraft 1.20.1 + Forge 47.x + Java 17 + Parchment。所属包 `com.miningdim.power`。
- 部署环境(硬约束): 公服 80 人在线、初始血量 80、TACZ 枪械、死亡不掉落。任何爆炸/伤害一律按 %最大血量, 不套原版 TNT 定值(见 `docs/MiningDimension_Mod_DesignSpec.md` 与经济总表)。
- 系统定位: 电力系统分三层 —— 发电(自研, 另立文档)、储能/传输(线缆=本文档; 无线 Flux Networks=终局)、用电(各机器)。本文档只覆盖"有线线材"这一层。
- 强依赖: 传输层已落码的网络引擎(见第二章); 反洗钱经济总表 `docs/Economy_BalanceSheet_DesignSpec.md`(任何产能/损耗都是隐性 faucet/sink, 须过账); 矿物世界 `docs/MiningDimension_Mod_DesignSpec.md` / `OreSystem`(新矿走它)。
- 设计北极星: 参考现实电缆制造与材料学做"风味", 不做 1:1 工艺仿真; 分级门槛=矿物稀有度 + 提纯次数/灌注料稀有度, 不堆机器。
- 状态图例: DECIDED 已定稿 / PENDING 待标定(占位数值须过经济总表) / TODO 实现期补全。
- 抗掉刻铁律(贯穿全文): 任何机制的 per-tick 成本必须 O(活跃端点数), 绝不 O(线缆块数); 温度是每张网一个值(per-network), 距离/线阻在网重建时算并缓存, 不进每 tick 结算。

## 一、系统定位与设计目标 (DECIDED)

1. 定位: 有线 FE(Forge Energy) 线材系统, 是"可获取的前中期主力传输层", 终局毕业到 Flux Networks 无线(Flux 被硬门槛稀有化)。
2. 12 级导体阶梯, 用四条真实轴叠出(见第四章), 非"12 种金属各一级"(现实里多数金属不是导体线芯)。
3. 生矿不能直接用: 至少经合成加工, 高级导体经"提纯机"多次提纯(灌注料逐级升级); 但最低 1-2 档保留 raw 合成以 bootstrap(见第五、八章)。
4. 热学: 过载升温、升温降效, 温度是每张网一个值; 绝缘等级=耐温档; 导体温度系数=降效 floor(见第三章)。
5. 数据驱动: 一切从 `ConductorMaterial` 表生成, 加一级=加一行数据(见第十章)。
6. 一切产能与损耗均须过反洗钱经济总表核对再定占位数值。

## 二、传输网络引擎 (DECIDED, 已落码, GameTest 绿)

已实现并 `runGameTestServer` 全绿(702/702, 含 2 个 energy_cable 测试)。包 `com.miningdim.power.cable` / `com.miningdim.power.grid`。

- `EnergyNetwork`: 一张连通网的运行时状态(成员线缆 map、端点 map、瞬态缓冲 stored、木桶吞吐帽)。全部驻内存, 不进 NBT(Powah #169 死因: 单块 NBT 存全网坐标致指数膨胀崩服)。
- `EnergyNetworkManager`: 每 ServerLevel 一实例。`addCable` 并网(merge)、`removeCable` 拆网(reflood 分量)、`markEndpointsDirty` 邻居变化标脏; `LevelTickEvent` END 每 tick 结算: 端点惰性重算 + 从生产端(canExtract)拉入缓冲 + 推给消费端(canReceive 且非 canExtract)。线缆方块实体**无 ticker**, per-cable 每 tick 成本=0。
- `EnergyCableBlockEntity`: 暴露 `ForgeCapabilities.ENERGY` 的 **receive-only** 能力(canReceive=true, canExtract=false), 挂网络缓冲。receive-only 杜绝"端点自拉 + manager push"双计。
- `EnergyCableBlock`: EntityBlock, `neighborChanged` 标脏端点。
- 反双计边界: 端点分类 canExtract=生产端(拉), canReceive 且非 canExtract=消费端(推); 两者皆真的电池 v1 当生产端(避免 churn)。

实现注记: 提交A 的 `CableTier` 五级占位枚举将被第十章的数据驱动 `ConductorMaterial`(12 级)取代/扩展; 网络引擎本身(合并/拆分/结算)不受材料层影响, 直接复用。

## 三、线缆热学模型 (DECIDED 机制 / PENDING 数值, 每张网一个温度)

现实背书: 焦耳定律 P=I²R —— 负载 75%→100% 电流仅 +33%, 发热却 +78%(1.33²), 支撑"过载后升温超线性"; 金属正温度系数 R(T)=R0[1+α(T−T0)] —— 温度升则电阻升则效率降(石墨烯是负温度系数, 见第四章特殊件)。

- **网温 T (per-network)**: 一整条连通网共享一个温度(用户确认), 不逐根线缆模拟。O(1)/settlement 更新。
- **安全持续线 = 额定 R 的 75%**(用户定, 非 50%): 本 settlement 吞吐 L ≤ 75%R → T 向环境 T0 缓慢回落; L > 75%R → T 上升, 速率 ∝ (L/R − 0.75)(超得越多升越快)。
- **温度 → 有效吞吐**: 有效吞吐 = R × eff(T)。T0 时 eff=1.0; 升温 eff 下降至 **floor**。
- **降效 floor 逐级不同 ∝ 导体温度系数**(低系数=耐热=floor 高): 铁(α=0.0065)floor 最低降得最快, 金(α=0.0034)floor 最高最耐热。所有 floor 都 ≤ 约 50%R(至少比 75% 安全线再低 1/3)。
- **绝缘等级 = 耐温档**: 绝缘决定"允许升到多高温才开始/加剧降效"。低级 PVC(70°C)一过载即软化降效; 高级硅橡胶(180°C)扛更高温才降效。导体纯度定容量, 绝缘定耐热, 双轴各司其职。
- **冷却回升**: L 回落至 75%R 以下, T 按时间常数缓降, eff 爬回 1.0。
- **距离/线阻(可选叠加, rebuild 缓存)**: 每级线缆有每格线阻, 网重建时算一个"距离效率乘子"缓存; 长网损耗大。绝不进每 tick。送达 = 吞吐 × eff(T) × eff(距离)。

PENDING: 升温/冷却速率、各级 floor 精确值、eff(T) 曲线、绝缘耐温映射, 均待标定并过经济总表(损耗是隐性 sink)。

## 五、提纯机 Metallurgic Purifier (DECIDED, 仿 Mekanism 冶金灌注机)

机制参照 Mekanism 冶金灌注机(官方 wiki 核实): 双输入(基材槽 + 灌注料槽) + 单输出 + 内部**灌注缓冲区**(灌注料被消耗后累积成带类型的缓冲, 达配方要求量才连同基材消耗产出) + **吃电**(Mek 为 20 RF/t; 我们仿一个 FE 功耗)。同一灌注类型可由多种源物品填(如 Mek 的 Carbon 可用煤/木炭)。

规则:
- **越高级 = 过提纯次数越多 + 灌注料越稀有**(分级旋钮), 不是重复同一步。
- **最低档不强制提纯**(第八章 bootstrap): 否则"要电才能提纯, 要提纯才有线送电"死锁。铁/生铜 raw 可搓。
- 铜提纯链(现实反直觉, 做成分支配方):

| 基材 | 灌注料 | 产物 | 对应级 | 现实依据 |
|---|---|---|---|---|
| 粗铜锭 | 硼砂(助熔) | 脱氧铜锭 | 中间 | 硼砂助熔吸附氧化物(注: 工业界对硼砂"助熔 vs 轻度脱氧"措辞混用, 不写死) |
| 脱氧铜锭 | 磷(便宜) | 磷脱氧铜锭 | 中档/导管 | 磷脱氧但残磷把导电率拉到约 80-98% IACS, 便宜但打折 |
| 脱氧铜锭 | 氩气(稀有) | 无氧高导铜锭 OFE | 6 | 真空/惰性气氛熔炼, 不引杂质, 101% IACS(与磷脱氧是两条工艺路线, 非升级) |

关键设计: 走"磷"便宜但只得导电打折的中档铜; 走"氩气"贵路才得真正顶级 OFE。玩家在成本与性能间取舍。

供电: 提纯机吃电, 强化"先有基础电力才能造高级电力设施"的引导环(capstone 递归)。开发期无发电机时用测试用假电源(同 GameTest 假源套路)顶。

灌注料汇总: 硼砂(第九章)、磷(可映射骨粉/骨头等磷源)、氩气罐(第六章)。

PENDING: 各配方灌注料单位数、FE 功耗、加工时间。

## 六、氩气罐·空气分离 (DECIDED, 顶级灌注料方案二)

顶级铜导体(OFE)所需"惰性气"= 氩气罐, 经"空气分离"制取。现实: 氩占空气 0.93%, 靠深冷分馏液化空气提取, 能耗极大; OFHC 高导电铜正是在氩/惰性气氛或真空下熔炼。

- **空分工序**: 空气(免费/易得) + **巨量 FE** → 氩气罐。稀有度来自能耗, 非新矿/worldgen。
- **设计意图**: 把顶级线缆门槛压在电力上 —— 要顶级铜线 → 要氩气 → 要巨量电 → 要先建好中级电网+发电机。最好的线缆=整个电力体系的终局毕业奖励。空分本身也是电力 sink。
- 零新矿、零 worldgen, 仅一个氩气罐物品 + 一台空分装置(或并入提纯机的一个高耗能配方)。

PENDING: 空分 FE 成本、氩气罐产率、是否独立机器 vs 并入提纯机高耗能配方。

## 七、绝缘 · 橡胶树 (DECIDED, 割胶机制)

唯一新植物。绝缘材料由橡胶树产出, 绝缘等级=耐温档(接第三章热学)。现实背书: 天然橡胶来自橡胶树割胶(tapping) —— 割破树皮取胶乳(latex), 加酸凝固后压干成橡胶; 树反复割不砍倒。

- **橡胶树**: 树苗→成树(丛林系)。树干可反复割胶, 不砍倒。
- **割胶**: 用割胶刀右键树干出胶点 → 生胶乳(latex)。该出胶点进入**冷却**(树缓慢再生胶乳), 冷却=反洗钱限速阀, 防无限免费橡胶 faucet(橡胶虽低值也须过经济总表, 不给白嫖)。
- **凝固干燥**: 生胶乳 →[熔炉 或 合成(+凝固剂如醋/酸)] → 橡胶(天然胶, 对应基础绝缘 PVC/PE 级)。
- **高级绝缘**(EPR/XLPE/硅橡胶): 橡胶 + 额外合成步(合成橡胶, 现实里本就是合成高分子非天然胶), 不直接从树来。高级线缆用高级绝缘=更耐热。
- 砍树另得木材(可选副产); 割胶是可再生橡胶源。

新增: 橡胶树(+树苗)、割胶刀(工具)、生胶乳(latex)、橡胶及各级绝缘料。

PENDING: 橡胶树 worldgen 参数、割胶冷却时长与单次胶乳产量、各绝缘档合成配方与耐温映射数值(均须过经济总表)。

## 八、加工链与配方 (DECIDED 结构 / TODO 具体配方)

全走合成表 + 一台提纯机, 不堆专用机器。生矿不能直接用。

```
生矿 →[原版熔炉] 锭
低档(铁/生铜): 锭 →[合成] 导线 →[合成] 导线+橡胶 → 成品线缆   (raw, bootstrap, 不过提纯)
```

- 收成约 3-4 游戏工序: 提纯锭 → 拉丝退火导线(合成一步, 不做多级中间物) → [镀锡/镀银可选] → 绞合绝缘成品。
- 分级门槛: 提纯次数 + 灌注料稀有度 + 矿物稀有度(高级矿限产=天然限高级线缆量)。

## 十、数据驱动架构 (DECIDED)

一切从 `ConductorMaterial` 表生成, 12 级=12 行, 加级=加行。字段(示意):

```
ConductorMaterial {
  id / 显示名,
  导体金属, 牌号(如 OFE C10100),
  额定容量 R (由真实导电率排序 + 经济总表),
  降效 floor (由真实温度系数),
  绝缘等级 (耐温档),
  purificationChain: [ (灌注料, 中间产物), ... ]   // 链长+稀有度=级别; 空链=raw可搓
  镀层 (可选: 镀锡/镀银),
  合成配方 (从上面字段生成),
  是否 bootstrap raw,
}
```

由该表生成: 线缆方块(×12)、中间物品、合成/提纯配方、blockstate/model/loot/lang(占位材质)。网络引擎(第二章)与热学层读该表取 R / floor / 绝缘。

## 十二、与经济/发电的接口 (DECIDED 原则 / PENDING 数值)

- 传输损耗(距离/过载降效被吃掉的部分)是隐性 sink, 须过 `docs/Economy_BalanceSheet_DesignSpec.md`。
- 高级导体的提纯/空分 FE 成本是电力 sink, 同样过账。
- 发电机(另立文档)将有内置 FE buffer=峰值×10 秒; 电网排不出→buffer 满过充→发电机升温→过热熔毁。线缆过热降效↔发电机过热是致爆闭环。本文档只需保证线缆侧接口(receive-only cap + 网温 + 有效吞吐)对发电机可见。
- Flux Networks 无线为终局层(硬门槛稀有), 与本有线层分层衔接。

## 十四、诚实边界与研究出处 (reference)

本文档的现实数据来自多轮 Workflow 检索 + 对抗式复核, 已知需谨慎处:
- 硼砂"助熔 vs 脱氧"工业界措辞混用, 文档表述为"兼助熔与轻度脱氧", 不写死。
- 磷脱氧铜导电率写区间 80-98% IACS(随磷含量), 非单值 85%。
- 退火温度按金属"常见于 300-600°C 区间", 非唯一标准值。
- 铝电工杆现实 9.5mm(铜 8mm), 若做风味注意区分。
- 所有 FE/t、温度阈值、配方数量均为占位, 落码前须过经济总表标定。
