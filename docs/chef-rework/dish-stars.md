## 计分规则（实际执行口径）

- 食材分档：T1 = 1 分，T2 = 2 分，T3 = 4 分；同一种食材只算一次，容器（碗、玻璃瓶、木棍、水桶/水瓶、炼药锅）不计分。
- 中间品按固定值计入（见下表）；附属 mod 的多食材中间品 = 各食材去重求和 + 1（合成/厨锅一步），上限 4；**单一食材的加工（切、烤、熏、倒进瓶子）不加分**，沿用原料分值。
- 菜品本身作原料（如汉堡→芝士汉堡、冰淇淋→奶昔、寿司→拼盘、水饺→饺子拼盘）：把子菜的食材并进来去重，不另加步骤分。
- 有多个配方时取最便宜的；标签槽位（A/B 任选）取最便宜成员——**如果标签里有本配方已用过的食材，则这一格记 0**（比如蔬菜杂烩的 #蔬菜 可以再放一个番茄）。
- 多份放置型（盛宴、整派、整块蛋糕、拼盘、披萨、火锅等）另加 3 分。
- 星级：1–2★1，3–4★2，5–6★3，7–8★4，9–10★5，11–13★6，≥14★7。
- 配方覆盖：同一路径的配方，后加载的 mod 胜出（Delightful 声明在几乎所有乐事 mod 之后加载）。所以本服的**实际**配方是覆盖后的版本，见下方「本服配方被改写的菜」。

## 本服配方被改写的菜（影响星级）

- **汉堡类**（FD 汉堡包、Delightful 芝士汉堡/豪华芝士汉堡、More Delight 简单/鸡蛋/豪华汉堡、文化乐事茄子汉堡、随性乐事驴肉火烧）：Delightful 检测到 SAR 的汉堡面包，把面包换成了 #forge:burger_bun（3 分）。
- **FD 炒饭**：被文化乐事覆盖，必须加玉米（T2）→ 6 分 ★3。
- **FD 羊肉卷饼**：被 Delightful / 文化乐事覆盖成玉米饼（3 分）→ ★3。
- **FD 培根三明治**：被 More Delight 覆盖成两片面包片。
- **BnC 乳蛋饼 / 披萨 / 火腿奶酪三明治 / 奶油洋葱汤 / 蔬菜煎蛋卷 / 奶酪意面**：Delightful 改成用 #forge:cheese 标签，可用随性乐事芝士片代替 BnC 奶酪。
- **原版蛋糕**：Delightful 改成用 #forge:dough（面团）。
