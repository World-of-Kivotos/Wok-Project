# 厨师重构设计资料（2026-10）

厨师职业重构设计与当前实现状态。九台烹饪台均已接通单份家常制作与掌勺生产，三种外观功能相同。右键打开九个原料槽、容器、调料与出品槽；炸锅、烤炉、备餐台分别使用 `miningdim:frying`、`miningdim:baking`、`miningdim:preparing`，共享扣料、信用点事务、服务器回放与恢复。烤炉按菜品翻面，备餐台按节拍摆料，冷饮沿用备餐台的等距节拍。家常免费且无经验，掌勺默认每份 5 信用点。练习从菜单按钮进入，不扣料、不产出、不授予经验；`/chef practice` 仅供管理员调试。[游戏内测试说明](../Chef_Zhangshao_MC_Playtest.md)。

正式生产表覆盖 109 个菜品 ID：原新台子清单 104 道，加五道厨锅炸物迁入；按逐菜动作表分配为炸锅 9、烤炉 37、备餐台及冷饮 63。星级取 `dish-stars.tsv`，台子和动作取 `dish-play.json`；`stations.md` 的 36/64 汇总差异记于 [迁移数据说明](../../tools/chef_recipes/README.md)，不改写设计真源。两道原版鱼类基础菜继续保留。

旧菜谱在每次资源重载时按最终资源包优先级迁移，保持原 recipe ID、原料及数量、容器、产量、处理时间和 Forge 条件；不会用素材缓存覆盖整合包实际配方。旧随性乐事炸锅合成入口和四条临时 WOK 重复菜谱被精确移除。未安装来源 MOD 时不会凭空新增对应物品或原料。生成器、来源哈希与同名配方冲突证据位于 `tools/chef_recipes/`。

同款切片拼回整件保留来源合成，不进入掌勺生产，避免切开与重组循环获取经验、手熟和成就进度。已核实 11 组整件与切片关系，以菜品的 `reassemblyItem` 数据匹配实际原料，不依赖配方 ID；同款切片以外的新增食材仍按正常菜谱迁移。

核心设计规则：一道菜固定一个厨师效果，星级决定数值，品质只决定时长（低 3 分 / 中 8 分 / 高 15 分 / 超凡 30 分 / 闪耀 = 单命永久）。每个大类同时最多 1 个永久 + 2 个限时；盛宴只有第一份能出永久。41 种新固定效果当前仍是后续实现，不应视为已接入炸锅生产。

九台生存合成配方均已开放。生产库存写入版本 3，已发布版本 2 的六原料槽、容器、调料、出品和暂存材料按明确槽位迁移，journal 检查点使用同一路径。旧调味存量兼容保留；41 种新固定职业效果、批量与快手、FD 厨锅正式掌勺接管仍属后续实现。

相关工具：

- `tools/chef_minigame/`：掌勺小游戏的确定性内核（`sim/sim.js`，JS 与 Java 逐位一致）、机器人平衡仿真、Java 移植参考与金样本、网页试玩原型的源码。
