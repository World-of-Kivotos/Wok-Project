# 枪匠组件命名计划

> 状态：基础组件命名已落实，后续扩展要求待实施。本文件不等同于新增配件功能的实现计划。
> 关联规格：[军火商职业设计规格](Munitions_Job_DesignSpec.md) 第 3A 节。

---

## 一、修改原因

现有六类枪械配件在显示名中直接使用“平台 + 槽位 + 品质”，容易将槽位类别误解为已存在的组件变体，也无法为后续新增配件类型预留清晰的命名层次。本次统一在显示文本中加入“基础”，明确当前内容均为基础组件，并同步修正规格中已过时的属性映射描述。

## 二、五个概念必须区分

| 概念 | 含义 | 当前示例 | 不能混同为 |
|---|---|---|---|
| 平台 | 枪械兼容族；决定组件可装配到哪些枪械。 | `AR`、`AK` | 槽位类别或品质 |
| 槽位类别 | 枪械上的装配位置；当前为导气、枪管、枪机、枪托、护木、握把。 | `导气` | 组件类型或平台 |
| 组件类型 | 同一平台、同一槽位下的结构或功能变体。 | 当前六类均为`基础`组件 | 槽位类别本身 |
| 品质 | 掉落/冲压品质档位；决定品质展示与浮动系数区间。 | `传奇` | 组件类型或平台 |
| 浮动系数 | 品质区间内 roll 得到的单件数值系数。 | `1.36-1.50` 中的一次结果 | 品质名称或新组件类型 |

因此，`AR基础导气 传奇` 的含义是：AR 平台、导气槽位、基础组件类型、传奇品质；其具体浮动系数仍是该物品的单独信息。

## 三、当前显示规则

### 3.1 物品名

格式：`{平台}基础{槽位类别} {品质}`。

- 示例：`AR基础导气 传奇`、`AK基础枪管 军规`。
- 当前六类槽位均使用“基础”：基础导气、基础枪管、基础枪机、基础枪托、基础护木、基础握把。
- “基础”是当前组件类型的显示文本，不是平台名、槽位名或品质名。

### 3.2 界面组件标签

当前压装与组装界面复用同一组 `gunsmith.part.*` 显示键，因此组件选择项和蓝图要求栏位也显示“基础导气”“基础枪管”等基础组件名称；压装界面与平台组合后显示 `AR基础导气`、`AK基础枪管`。

- 品质与浮动系数仍只跟随具体物品，不写入界面组件标签。
- 平台限制与蓝图要求仍由既有兼容规则决定，显示文本不参与判定。
- 复用显示键是当前基础组件阶段的实现现状；新增非基础组件类型时，必须拆分“槽位类别键”和“组件类型键”，不能继续用一条文本同时承担两个概念。

### 3.3 成品 tooltip

已装配成品按槽位逐项显示组件类型、品质与浮动系数，当前格式为：`基础导气 传奇 1.42x`。成品枪已有确定的平台，因此组成列表不重复显示 `AR` 或 `AK`。

- 成品 tooltip 保留“基础”组件类型，不退回只显示“导气”等旧名称。
- 属性说明按当前映射显示：枪机伤害、枪管爆头倍率、导气射程、枪托后坐力、护木散布、握把开镜/瞄准散布。
- 未装配槽位不伪造组件名称或系数；具体空槽提示由既有 UI 规则决定。

## 四、本次范围与兼容承诺

本次只落实六类基础组件的显示文本，并同步设计说明；不修改或新增玩法数据：

- 仅修改既有中英文 `gunsmith.part.*` 组件名称及 M4 模板需求说明；不改语言 key、物品注册名或资源标识。
- 不改 NBT 字段、序列化结构或已有物品数据。
- 不改配方、冲压逻辑、属性数值、品质区间或兼容判定。
- 不新增组件、平台、槽位、蓝图、UI 分类或经济产出。

现有存档、已有组件与既有装配兼容行为不因本次显示文本变更而改变。

## 五、后续新增组件类型的前置要求

若未来在同一平台和槽位下新增非基础组件类型，必须新增独立的 `variant` 维度。不得把组件类型塞入平台名、槽位名、品质名或浮动系数，也不得仅靠显示文本区分。

实施前至少应完成以下事项：

1. 定义 `variant` 的稳定数据值、数据版本与旧物品迁移路径，确保旧的基础组件可被明确识别并迁移。
2. 为每个新组件类型定义取得或制作蓝图，以及蓝图解锁、消耗和来源规则。
3. 在装配、背包筛选和 tooltip 中增加明确的 UI 分类，避免同槽位组件难以比较或误装。
4. 重新评估冲压成本、掉落/产出、品质区间、属性上限和平台差异，完成经济与战斗平衡审查。
5. 补充 GameTest，至少覆盖新旧数据迁移、平台兼容、槽位限制、装配结果、属性映射和不兼容组件拒绝路径。

## 六、非目标

本次不是新配件内容更新，未实现且不应据此假定已经存在：

- 非基础组件类型或 `variant` 数据字段。
- 新的物品 key、NBT、配方、蓝图、掉落表或数值平衡。
- 新平台、新槽位或弹匣/供弹具进入冲压体系。
- 除六类既有本地化显示值外的 UI 布局、tooltip 格式或成品组装逻辑改动。
- 数据迁移或 GameTest 的新增实现。

本文件只为当前六类基础组件建立一致的命名和显示口径，并列出未来扩展时必须完成的工程工作。
