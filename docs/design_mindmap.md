## 矿洞维度 · 本体
- 副本世界:单维度 + region 网格切副本,可整体重置
- 三难度:Easy / Medium / Hard,矿物权重随难度
- danger 压力:停留累积 + 区域难度 + 矿富集 → 后方刷怪
- 陷阱:静态布点 + 动态触发
- 经济反滥用:每日高价矿上限 / AFK 冻结 / 收购价递减 / 重置成本
- 进入与回退:EntryGateway;复活点恒为进入前坐标;死亡物品规则按难度分档 —— EASY/MEDIUM 不掉落,HARD 强制掉落全部背包物品(rules/MiningDeathRules,进入时红字明示,难度表见 docs/archive/delivered/TaskSpec_Mining_DeathRules.md,已交付冻结件)

## 职业

### 矿工(效率向 · 1-10 · 成长式)
- 探测类(开关/脉冲 + 长 CD)
  - 矿物探测:脉冲高亮选定矿,CD 300→180s,半径 6→16,矿种 L3 铁/煤/铝土;L6 +钻/硼砂/锡/银;L8 +金/残骸/镍/铬/钨(见 OreScanService)
  - 陷阱探测:高亮陷阱,CD 240→150s,L5 非致死 → L8 含致死
- 速挖类(开关 + 充能)
  - 连锁挖矿:充能 16→48 块,整池回满 ~5→3.5 分;2026-07-12 裁决矿洞内全放开,旧的白名单/高价矿硬排除双表已删,唯一判定是 ChainMiningEngine.chainable(镐可采+档位够+可破坏+无方块实体)
  - 隧道挖(L9):3×3 仅普通方块,CD 30→20s
- 被动类(纯成长)
  - 挖矿提速:+15% → +110%
  - 省耐久:5% → 30%
  - 抗疲劳:L4 起免疫挖掘疲劳
  - 便利:自动入包 / 自动熔炼(可关)
- 获取更多矿
  - 时运:额外掉落 +8% → +50%(方案 B + 隐藏软上限,计产出物)
- 生存类(守"不漂战斗力")
  - 耐压:减 danger 时间项累积 0.85x → 0.6x 封底
  - 矿脉抗性:−10% → −35%;陷阱专属 DamageSource 未落地,现按原版环境伤类型集合近似识别(MinerSurvival.isTrapSource),对近战/远程/枪伤与玩家 TNT 零作用,但苦力怕等非玩家爆炸连带被减伤
  - 脱险归途(L7):撤离,CD 8→5 分,读条可打断
  - 声东击西(L9):降压窗,CD 5→3.5 分
- 难度门控:L4 开 Medium / L8 开 Hard
- 经验:谁挖谁得(BreakEvent 落在实例内),复用 61900 曲线
