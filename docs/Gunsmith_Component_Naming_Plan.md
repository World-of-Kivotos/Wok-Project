# 枪匠组件命名计划

> 状态：基础组件命名、特殊组件 `variant`、势力标识与五档稀有度名牌均已落实。
> 关联规格：[军火商职业设计规格](Munitions_Job_DesignSpec.md) 第 3A 节。
> 统一制作规范：[枪匠新组件制作规范](Gunsmith_Component_Creation_Rules.md)。
> 平衡边界：[枪匠组件平衡与后续扩展路线](Gunsmith_Component_Balance_Roadmap.md)。
> 首个特殊组件：[格赫娜高速导气组件规格](Gunsmith_Gehenna_High_Speed_Gas.md)。

---

## 一、修改原因

现有基础枪械配件在显示名中直接使用“平台 + 槽位 + 品质”，容易将槽位类别误解为已存在的组件变体，也无法为后续新增配件类型预留清晰的命名层次。本次统一在显示文本中加入“基础”，并为机枪平台预留基础脚架命名，明确当前内容均为基础组件，同时同步修正规格中已过时的属性映射描述。

## 二、六个概念必须区分

| 概念 | 含义 | 当前示例 | 不能混同为 |
|---|---|---|---|
| 平台 | 枪械兼容族；决定组件可装配到哪些枪械。 | `AR`、`AK`、`MACHINE_GUN` | 槽位类别或品质 |
| 槽位类别 | 枪械上的装配位置；当前基础组件包括导气、枪管、枪机、枪托、护木、握把，机枪平台另有脚架。 | `导气`、`脚架` | 组件类型或平台 |
| 组件类型 | 同一平台、同一槽位下的结构或功能变体。 | `基础`、`AR三连发枪机`、`格赫娜高速导气` | 槽位类别本身 |
| 组件型号稀有度 | 由稳定 `variant` 固定决定的型号层级。 | `制式级`、`特种级`、`原型级` | 冲压品质或获取难度 |
| 品质 | 掉落/冲压品质档位；决定品质展示与浮动系数区间。 | `传奇` | 组件类型或平台 |
| 浮动系数 | 品质区间内 roll 得到的单件数值系数；当前基础组件按属性映射使用，未来特殊组件还需另列正负效果。 | `1.36-1.50` 中的一次结果 | 品质名称或组件类型 |

因此，`AR基础导气 传奇` 的含义是：AR 平台、导气槽位、基础组件类型、传奇品质；其具体浮动系数仍是该物品的单独信息。

## 三、当前显示规则

### 3.1 物品名

格式：`{平台}基础{槽位类别} {品质}`。

- 示例：`AR基础导气 传奇`、`AK基础枪管 军规`。
- 现有基础槽位均使用“基础”：基础导气、基础枪管、基础枪机、基础枪托、基础护木、基础握把；机枪平台的脚架显示为“基础脚架”。
- “基础”是当前组件类型的显示文本，不是平台名、槽位名或品质名。

### 3.2 界面组件标签

当前压装与组装界面复用同一组 `gunsmith.part.*` 显示键，因此组件选择项和蓝图要求栏位也显示“基础导气”“基础枪管”等基础组件名称；压装界面与平台组合后显示 `AR基础导气`、`AK基础枪管`。

- 品质与浮动系数仍只跟随具体物品，不写入界面组件标签。
- 平台限制与蓝图要求仍由既有兼容规则决定，显示文本不参与判定。
- 复用显示键是当前基础组件阶段的实现现状；新增非基础组件类型时，必须拆分“槽位类别键”和“组件类型键”，不能继续用一条文本同时承担两个概念。

### 3.3 成品 tooltip

已装配成品按槽位逐项显示组件类型、品质与浮动系数，当前格式为：`基础导气 传奇 1.42x`。成品枪已有确定的平台，因此组成列表不重复显示 `AR` 或 `AK`。其中 `1.42x` 表示该组件保存的单件浮动系数；当前基础组件按既有属性映射使用该系数，未来带有正负取舍的特殊组件必须另外显示完整的最终属性变化。

- 成品 tooltip 保留“基础”组件类型，不退回只显示“导气”等旧名称。
- 属性说明按当前映射显示：枪机伤害、枪管爆头倍率、导气射程、枪托后坐力、护木散布、握把开镜/瞄准散布。
- 机枪平台组件规格另见[机枪平台组件规格](Gunsmith_Machine_Gun_Components.md)；其中基础脚架影响操控与瞄准稳定，固定射程属性为 `1.0`。
- 未装配槽位不伪造组件名称或系数；具体空槽提示由既有 UI 规则决定。

### 3.4 tooltip 稀有度名牌与势力标识

物品图标不再承担组件型号稀有度展示。鼠标悬停组件时，在物品名下方绘制横向稀有度名牌；具有明确世界观制造来源的特殊组件同时在名牌右侧显示势力或集团 LOGO。二者只负责组件来源与型号定位，不新增枪械平台，也不改变平台兼容、槽位、品质、属性或装配判定。

组件型号稀有度与冲压品质是两套独立维度：

| 稀有度 | 当前组件型号 |
|---|---|
| 制式级 | 全部基础组件 |
| 改装级 | AR三连发枪机 |
| 特种级 | 格赫娜高速导气、红冬高压导气、赤雪-A枪机 |
| 尖端级 | 圣三一精密刻度 AR 枪管、圣三一精密刻度狙击枪管 |
| 原型级 | MK-AX-A枪机 |

稀有度由稳定的 `variant` 定义直接派生，不重复写入物品 NBT。同一型号仍可分别具有普通、改良、军规、精密、传奇五档冲压品质。

名牌处理规则：

- 五档名牌使用独立的 `76x20` 真透明 PNG，采用同一套紧凑学院战术科幻结构，并以白、蓝、绿、紫、红的全框光路区分等级；tooltip 中按原始尺寸一比一绘制，文字只显示“制式级、改装级、特种级、尖端级、原型级”，不追加“组件”。
- 名牌贴图不烘焙文字；中英文名称由客户端本地化动态绘制在深色中央窗口内。
- 势力 LOGO 直接使用用户提供的 `160x160` 高清透明原图，在名牌右侧按 `24x24` 显示；客户端缩放时启用线性过滤，不生成或放大低分辨率像素化派生图。
- 势力 LOGO 保留自身识别色，不随组件品质或稀有度改色；名牌与 LOGO 必须同时可辨认。
- 同一势力或集团的角标必须复用同一标准资源，不得在不同组件上各自重新描绘。
- 普通基础组件没有势力 LOGO，但仍显示制式级名牌。

### 3.5 文档记录规则

- 枪匠设计文档、组件规格、平衡表和实现清单只要列出具体组件型号，就必须逐项记录组件型号稀有度，不得只写品质、颜色或“稀有组件”。
- 已实现型号的文档值必须与 `GunsmithPartVariant` 的固定稀有度映射及本文件第 3.4 节同步；同一型号在不同文档中不得出现不同稀有度。
- 尚未实现的设计条目必须写明拟议稀有度并标记状态；未声明稀有度的条目不能进入 DECIDED 或实现阶段。
- 文档中的“获取稀有度”必须另行表述图纸、掉落、制作或交易难度，不能代替制式级至原型级的组件型号稀有度。

## 四、运行期数据与兼容承诺

- `variant` 保存组件具体型号；旧组件没有该字段时按 `BASE` 读取并显示制式级名牌。
- 稀有度由 `variant` 固定定义，不新增或重复保存稀有度 NBT；修改物品品质不会改变型号稀有度。
- 名牌与势力 LOGO 只改变 tooltip 展示，不修改任何组件正负属性、冲压品质区间、浮动系数或获取规则。
- AR 与 AK 永久沿用现有六槽；三连发枪机、MK-AX-A 和赤雪-A 均复用 `BOLT`，不得新增 `RECEIVER`。
- 中英文名牌文本由本地化键动态绘制，资源包替换语言时无需重做贴图。

## 五、后续新增组件类型的前置要求

后续在同一平台和槽位下新增组件型号时，必须继续使用稳定的 `variant`，并明确声明五档稀有度之一；不得把组件类型或稀有度塞入平台名、槽位名、品质名或浮动系数。

实施前至少应完成以下事项：

1. 定义稳定的 `variant` 数据值、适用平台、既有槽位和旧物品迁移路径。
2. 在组件规格、平衡表和实现清单中记录组件型号稀有度，并与实现映射同步。
3. 明确正面收益、负面代价、取得或制作蓝图、消耗和来源规则。
4. 在装配预览与 tooltip 中完整显示正负效果，并为组件选择提供清晰分类。
5. 重新评估冲压成本、获取稀有度、品质区间和平台差异，完成经济与战斗平衡审查。
6. 补充 GameTest，至少覆盖稀有度映射、平台兼容、槽位限制、装配结果、属性结算和拒绝路径。

基础组件与特殊组件的边界、射速禁区和极致强化组件的强制代价，以[枪匠组件平衡与后续扩展路线](Gunsmith_Component_Balance_Roadmap.md)为准。

## 六、非目标

- 稀有度名牌本身不调整现有组件配方、掉落表、属性数值或经济产出。
- 不新增枪械平台、装配槽位或弹匣/供弹具。
- 不把势力 LOGO 当作平台、品质或稀有度，也不要求所有未来势力立即补齐正式资源。
- 不把名牌几何叠加到 `64x64` 物品图标；品质描边与组件本体图标继续保持既有资源规则。
